# Orbis 可选宠物原画

轻量形象随应用提供。大图只在使用者选择原画时获取，按宠物分包，多位助手使用相同形象时共用一份。

`orbis-pets/` 是原画源文件，`dist/` 是由 `tools/build_optional_pet_art.py` 生成的独立 ZIP。应用只打包 `app/src/main/assets/orbis-pet-art.json` 索引，不打包本目录。

使用入口：工具与娱乐 → 宠物区 → 布置 → 下载并使用这只宠物的原画。离线可下载对应 ZIP 后在同处导入。

已开启宠物工具的 AI 可用 `orbis_pet(action=art_info)` 查询自己宠物的下载地址、字节数和 SHA-256；得到人类使用原画的请求后，用 `install_art` 由宿主下载、校验并安装，不必经过工作区。房间配色使用 `decorate` 的 `sage`、`rose`、`sky`。

原画清理只处理校验一致的官方可选包，保留所有助手已领养宠物、自定义导入与宠物档案。关闭模块或关闭原画显示不会删宠物。下载失败继续使用轻量形象。

猫房间提供三套独立配色原画，黑猫提供三套独立睡眠画面并保留进食、饮水姿态。其他 39 种宠物各有睡眠、进食、饮水与三种配色组成的九格照料素材；非猫日常房间沿用背景调色。已有姿态图集继续保留，不借用其他宠物的外形。

如需重新生成素材包，安装 Python 的 Pillow 后，在仓库根目录运行 `python3 tools/build_optional_pet_art.py`。脚本会生成 `optional-assets/dist/`，并更新应用素材索引；发布自建素材包时须同步修改索引地址和校验值，不能把本地产物误当作已经上传。编码库版本变化可能影响 WebP 字节和哈希。
