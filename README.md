# Orbis 宠物原画包

供 Orbis「工具与娱乐 → 宠物区 → 布置」按需下载。每只宠物只需自己的 ZIP，多个助手可共用，不需要下载全部。

应用内「下载并使用这只宠物的原画」会自动校验并安装；已安装旧包可点「更新这只宠物的睡眠与吃喝画面」。也可下载 `packs/` 下对应 ZIP 后从「导入原画包」安装。AI 可通过 `art_info` 读取当前宠物地址和校验值，收到人类使用原画的请求后，通过 `install_art` 安装当前宠物，不必在工作区中转。

40 种宠物均支持草绿、暖粉、雾蓝三种配色及独立睡眠画面。黑猫沿用原有三色睡眠画面与对齐后的吃喝动作；其余 39 种宠物使用各自的九格照料画面（睡眠、进食、饮水 × 三色），醒着时仍用各自形象与原有房间。猫以外的常态房间采用背景调色，照料画面为独立绘制。并非所有宠物都有完整逐帧动画。

资源与 Orbis 内测 20 及以后版本配套。`catalog.json` 记录字节数与 SHA-256；应用固定到已核验的提交，旧版本仍可下载旧资源。新素材验证成功后才移除对应旧官方文件；自定义图片不自动替换。清理其他未领养的官方素材时会保护所有助手正在使用的宠物。

这里只存放可重新下载的官方图像资源，没有用户聊天、设置、凭据或宠物档案。图像由图像生成工具制作。
