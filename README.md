# Orbis 宠物原画包

供 Orbis「工具与娱乐 → 宠物区 → 布置」按需下载。每只宠物只需自己的 ZIP，多个助手可共用，不需要下载全部。

应用内「下载并使用这只宠物的原画」会自动校验并安装；也可在本目录 `packs/` 下载对应 ZIP 后从「导入原画包」安装。应用内的 `art_info` 会给 AI 返回当前宠物的下载地址和校验值。

猫房间包括草绿、暖粉、雾蓝三种配色；黑猫包括三套独立睡眠画面。其余动物仍使用自己的形象，原画房间支持背景调色。`catalog.json` 记录版本、字节数和 SHA-256。

这里只存放可重新下载的官方图像资源，没有用户聊天、设置、凭据或宠物档案。
