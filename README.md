# Orbis

Orbis 是一个原生 Android AI 客户端。除了聊天，它把本地后花园、藏书阁、海龟汤、宠物与学习陪伴、语音台和可选的手机工具放在同一个应用里。

可以先把它当作一个普通聊天客户端使用，再按需要开启其他功能。无需先购买 VPS，也无需加入任何公共服务。

从聊天开始，按需要开启记忆、陪伴和工作工具；完整功能和使用步骤见下方指南。

## 能做什么

- **拒绝的权利**：人类选择委托范围，AI 可以暂停单个对话或整个助手、选择可用能力；继续申请进入原聊天，到约定时间自动恢复。
- **AI 自检与按需说明**：从当前助手工具设置检查授权、配置和故障线索，详细教程按需查询，配置目录分页返回。

- **AI 自定义主题与身体状态**：AI 可以设计聊天外观；身体状态按其规则、对话与静默时间变化，语音条最终转写也能参与。
- **许愿式部署 ST**：先确认手机、电脑或 VPS，AI 按需查指南准备环境与连接；手机托管实例可随应用重开恢复。
- **问卷、续局与撤回**：作品可保存和查询，小游戏从已有存档继续；人类和 AI 分别撤回自己的消息。


- **角色小部件**：内置可直接使用的「知序」形象，支持动作、表情、独立发色与瞳色、时钟及问候；也可导入自己的素材。全屏房间暂不开放。[设置与边界](docs/CHARACTER-INTERACTION.md)。
- **一起看屏幕**：经人类授权按间隔看图，紧凑浮窗能拖动、收进侧边，麦克风与 AI 外放分别控制；结束后留下文字总结。[入口与边界](docs/SCREEN-SHARING.md)。
- **互相传 ZIP**：人类发送资料 ZIP，AI 分页读取受支持的文字；AI 也能生成可保存的文字 ZIP 附件，不执行压缩包中的代码。[AI 使用步骤](docs/AI-QUICKSTART.md)。

- **原生 AI 聊天**：配置自己的模型提供商和助手，使用消息分支、Markdown、附件、搜索、朗读及按需工具。具体能力取决于模型和服务配置。
- **本地后花园**：在手机保存日记、锚点、信件、心愿等文字，设置自己的展示称呼；不需要账号或 VPS。
- **本地藏书阁**：导入 TXT、Markdown 文字书籍，保存阅读进度、书签和批注；可让当前 AI 按章节片段共读。
- **本地海龟汤**：与自己的 AI 伙伴一起推理，由另行选择的 DM 模型主持。主持接口与主聊天上下文分开。
- **快捷聊天**：在后花园里点“聊聊”，选择当前 AI 的已有窗口。消息存回原窗口，不自动附带书页或汤底。
- **宠物与学习陪伴**：宠物房间提供多动作渐变、AI 互动、照料记录、寄养及累计照料奖励；离开应用后按经过时间结算状态。学习区支持题库、练习、错题、专注与学习记录。宠物是二维素材动画，不是实时三维模型。
- **语音与语音台**：用已配置的 TTS 直接试听音色、空间感、距离、滤镜、语速和音调；通话、语音条、朗读等播放路径沿用已保存配置。一轮开始后固定该轮声音，调整在下一轮生效，避免切断正在播放的声音。可不开启语音台。
- **多 AI 群聊与小游戏**：为不同成员选择身份和模型，顺序交流或点名；也可使用本地规则游戏和隔离的小游戏页面。模型参与时可能产生费用。
- **外观与阅读**：主题、背景、字体、气泡和消息阅读方式可按偏好调整。
- **聊天迁移与本地日程**：支持多种来源的聊天预览、选择和追加导入；提供本地课表、日程和颜文字管理。不同导入格式的保留范围不同，见本版说明。
- **格子与隐私室**：保存文字、HTML 和问卷作品；每位助手拥有独立隐私室，人类申请后由该助手选择分享内容。隐私室可另设恢复密码，也保留旧随机恢复码兼容；恢复密码不是向 AI 公开房间内容的许可。隐私室不需要另选模型或绑定 ST。
- **本机助手记忆与星图**：AI 按助手隔离保存、查询和管理便签；默认轻档不自动带入。按设置启用自动带入后，可对符合条件的记忆和压缩记录进行本机语义召回，帮助跨窗口衔接。星图展示元信息，人类可调整资源档位、停止自动带入或导出保全；向量缓存不是聊天原件。详见[原有记忆使用与边界](docs/LOCAL-ASSISTANT-MEMORY.md)及[本版新增范围](docs/RELEASE-2.6.12.md)。
- **让 AI 协助配置**：AI 可通过工具检查和填写模型角色、TTS、MCP、工作区连接及备份目标；需要密钥时仍由人类填写，MCP 保存后仍需开启。连接检测和实际操作回执分开，不能把“已填好配置”当作“服务已连通”。
- **可选 AI 全局观测**：默认关闭；开启后每轮提供精简的模型、助手、窗口和交互状态，并可按需查询窗口列表。不是将所有聊天正文自动交给 AI。
- **可选工具与陪伴**：后花园、日历、通知、语音、工作区、MCP，以及按规则唤醒等能力各有配置和权限边界。不用的功能可以不打开；旧 `native_memory` 工具已移除，本机助手记忆不会自动迁入旧库。

手机与陪伴能力已经内置，不需要另装配套的手机工具应用，也不需要为内置工具额外搭建 MCP 服务。模型、系统权限和你主动选择的外部服务仍需各自配置。

这些是功能入口，不是“已经连接成功”的证明。未配置的服务、被撤回的权限或不可用的模型，都可能让相关功能无法使用。

## 两种后花园用法

| 路线 | 需要准备 | 数据在哪里 |
| --- | --- | --- |
| 本地使用 | 手机；使用 AI 时另配模型 | 本机保存的花园、书库及对局 |
| 连接自建云端 | 你自己的 Orbis 网站，以及与它配套的 Supabase 等服务 | 由该网站及其后端管理 |

两条路线不是自动同步关系。切换不会自动搬运、上传、合并或删除任一边的数据。本地花园、书库和云端站点需要分别考虑备份。

自建云端是可选项。应用不会替你创建 Supabase 项目，也不附带可直接使用的公共站点、账号或数据库管理密钥。

## 模型和费用

Orbis 不附送模型账号、API Key 或调用额度。请自行配置可信的提供商、接口地址和模型，并查看其计费与隐私说明。

聊天、共读、翻译、模型对弈、语音服务和海龟汤主持等操作，可能分别调用你配置的服务。一个操作也可能包含多轮模型请求。不开启 AI 的本地记事与阅读不需要模型调用；“无需 VPS”不等于“远端模型免费或离线”。

## 咨询室：正在开发，暂不开放

开源版的咨询室关闭，北斗导航中不显示咨询室入口。系统设置保留“正在开发，暂未开放”的提示。相关源代码保留供开发与审查，但不提供配置、待命、加入或调用入口，也不能通过旧配置继续使用。请不要把代码存在理解为功能已开放。

咨询室不影响普通聊天、本地后花园、共读和海龟汤等其他入口的使用。是否开放将在后续明确说明，不承诺时间。

## 安装与备份

请从 [GitHub 发布页](https://github.com/AZHi-xinxin/Orbis/releases) 下载签名 APK。最低需要 Android 8.0；通常选择 `arm64-v8a`，不确定设备架构时选择 `universal`。通用包包含 `arm64-v8a` 和 `x86_64`，不包含 32 位 ARM；`x86_64` 主要用于对应架构设备或模拟器。主包与 Rescue 备份包同包名同签名，可互相覆盖，不是可单独卸载的插件；不要卸载或清数据。发布页中的源码压缩包不是安装包。上游 RikkaHub 的安装包也不是 Orbis。

正式版包名为 `org.orbis.agent`。`Orbis Dev` 使用 `org.orbis.agent.dev`，与正式版是两个独立应用，不会自动共享或迁移聊天、书库及设置。不要为安装正式版先卸载仍需保留数据的开发版。

**旧版更新遇到“签名不一致”时，请先不要卸载。** 2.6.1／2.6.2 的更新器在 Android 9／10 上可能读不到下载 APK 的证书而误报，2.6.3 已修正。受影响用户请从官方发布页手动下载当前正式 APK，直接覆盖安装一次，不清除数据；2.6.0 也可直接这样升级，无需逐版安装。若 Android 系统安装器仍报签名冲突，请停止并核对来源，不要绕过校验。

修复版的“系统设置 → 版本更新与回退”仍会检查官方新版本、展示说明，并在用户确认备份后下载校验 APK，再交给 Android 确认安装；不会静默下载或安装。自动检查最多每 24 小时一次，不是持续后台推送。Android 10 的证书读取修复已实机复现验证；从修复版到下一更高正式版的应用内完整升级仍待后续验收，详见[更新与回退说明](docs/UPDATES-AND-ROLLBACK.md)。

同包名、相同签名且版本允许时可覆盖升级；若安装器提示冲突，请先核对来源，不要直接卸载或清除数据。Dev 版不会把正式 APK 当作自身覆盖更新。

升级、卸载或清除数据前，先阅读[备份说明](docs/PRIVACY.md#备份不是全量镜像)。普通聊天 ZIP 不覆盖所有 Orbis 本地数据，也不要把它直接上传到公开问题区。

2.6.12 增加本地自动检查点、服务器备份/恢复入口与 AI 绑定通道；固定云端存档采用临时上传、校验和原子发布，失败时保留旧存档。需要兼容的服务器和实际成功的完成回执，排队不等于备份成功。卸载通常会移除应用私有数据，本机缓存不能代替已导出或已验证的外部备份。

2.6.6 增加本机记忆结构，当前数据库为 schema 31。升级后不要直接安装旧 APK 尝试回退；旧版未必能读取升级后的数据，需先核对备份及[回退边界](docs/UPDATES-AND-ROLLBACK.md)。[2.6.5 历史说明](docs/RELEASE-2.6.5.md)及旧发布资产继续保留。

## 本版已知限制

- 长窗口累积图片等附件可能使请求过大并出现 HTTP 413，附件发送预算尚未修复。不要将删除附件当作无损清缓存；清理可能移除需要保留的本地原件。
- 大型备份在慢链路上仍可能超过目前单次八分钟期限，未完成时旧云端存档保留；没有完成回执就不能当作新版已经上传。
- 自定义请求头在不同服务和请求间的作用范围仍需修正与复核，本版不宣称已解决。
- 原生库已更新到 ONNX Runtime 1.24.3，发布检查包含 16 KiB ELF / ZIP 对齐；16 KiB 内核设备的运行测试另行记录。
- 网络等待、后台限制和不同设备的通话/通知差异仍可能影响使用。完整范围见[本版说明](docs/RELEASE-2.6.12.md)。

## 反馈问题

请说明应用版本、Android 版本、操作步骤、预期结果和实际结果。不要附上 API Key、完整请求日志、聊天备份、私人正文或带授权信息的链接。能用无敏感内容的小例子复现，通常更容易定位问题。
