# 知序：内置基础小部件形象

这套通用形象由项目维护者提供原创人物草图，使用内置图像生成工具制作，用于让没有绘画或素材制作经验的用户也能直接使用 Orbis 小部件。

- 9 张动作：自然、邀请、挥手、抱臂、思考、捧杯、舒展、倾听、讲解。
- 24 张表情：平静、笑、哭、思考、生气、害羞、困、激动，各 3 张。
- 透明 PNG，1024 × 1536。原图保持不变；桌面显示时可叠加表情、换色和调整腰部收边。
- 发色、平常瞳色可分别选择十套配色。生气、激动时暂用深红瞳色，恢复其他表情后使用原选择。
- 配色：DeepSeek 蓝、GPT / Codex 白、Claude 橙、Gemini 蓝粉、Grok 黑、豆包紫、Kimi 灰、MiniMax 水红、GLM 银、MiMo 金。这些名称仅表示用户指定的外观，不表示厂商合作、官方角色或模型切换。
- 空白角色首次打开小部件设置时安装基础形象；已有私人立绘或图库不会自动替换。手动切换基础形象会先确认。
- 仅 colorModel=orbis-blue-v1 的内置配准素材支持此换色。任意导入图片不会被自动染色。

图像、清单与配准数据随项目根目录 LICENSE 发布。私人角色图片、私人台词、聊天、账号及模型密钥不包含在本目录中。生成提示词见 prompts.json；生成图是平面素材，不是分层 PSD 或已绑定的 Live2D 模型。

manifest.json 为立绘与触摸区域，presentation.json 为素材完整性摘要和小部件配置。更换 PNG 后需要更新 SHA-256 与尺寸；自制角色不要沿用本套的颜色遮罩或面部坐标。
