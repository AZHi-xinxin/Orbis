Rules, host prompt structure, and sample content were consulted from
https://github.com/AZHi-xinxin/haiguitang-coop (public `main`, retrieved 2026-09-28).

The five sample puzzles are by AZHi-xinxin / Haiguitang contributors, distributed
under CC BY 4.0: https://creativecommons.org/licenses/by/4.0/ .
Upstream notice: https://github.com/AZHi-xinxin/haiguitang-coop/blob/main/CONTENT_LICENSE.md .
Puzzle text is unchanged; only its JSON representation was converted to Kotlin.
No private puzzle bank is included. Two upstream samples have narrative ambiguities;
the native selector identifies these without revealing their solutions.

This native adaptation stores game state locally, requires a separate explicit
approval for each model request, performs no automatic retries, and computes the
published 40/30/30 score weights locally. Original web/cloud backend code is not run.
