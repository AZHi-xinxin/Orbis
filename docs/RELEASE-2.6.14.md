# Orbis 2.6.14

这次更新把 AI 自定义外观、身体状态、作品与记忆、ST 协助部署和日常操作连接起来，并修复聊天迁移、续局、通知及 Pro 缓存布局。

版本代码为 `280`，比公开 2.6.13（277）和两次 2.6.14 内测包（278、279）更高。正式版沿用 `org.orbis.agent` 与原发布证书；下载正式签名包后直接覆盖升级，保留原应用数据。Dev 版使用独立包名和数据空间。

## 外观与身体状态

- 侧栏增加独立「自定义美化」入口；AI 主题工作室支持预览、修订、应用和回退。打开「交给 AI 自由装扮」后，AI 可直接更换主题。
- 扩展气泡透明度、装饰尾巴、向量效果、角标与字体；系统默认字体跟随手机设置。
- 身体状态支持 AI 自定义规则、自动触发与静默变化，当前轮状态随模型请求传递。语音条使用最终转写参与计算，关闭消息时间显示也保持状态更新。

## 记忆、作品和日常

- 优化动态记忆、身体状态与用量提醒的请求布局，改善官方 DeepSeek Pro 的前缀缓存复用。ST 路径采用客户端与网关协商：服务器支持新版宿主资料协议后，再对实际 Pro 上游执行对应布局；Flash 和其他路由保持各自处理方式。
- 固定记忆与动态召回分别处理，增加图片记忆线索、本机愿望与相关工具入口。
- 问卷支持分页、条件与样式，修复手机选项点击和结果反复回填。
- 游戏机提供「待继续」与历史续局入口，旧盘面从作品已保存的 checkpoint 恢复；内置按需指南帮助 AI 接入存档接口。
- 人类记录支持日期分区、离线截图识别与校对、AI 补充和备注，以及可选的健康来源同步。
- Web 截图支持选取、裁剪和附件确认；普通 HTTP 下可粘贴系统截图或选择图片，直接浏览器捕获使用 HTTPS / localhost。

## AI 帮你部署与管理连接

- 人类操作教学、ST 安装和排错按需查询，提供具体点击路径与前置准备说明。
- 部署前确认手机、电脑或 VPS，工作区诊断区分权限、Rootfs 和托管实例登记。
- 手机工作区支持 ST 持续运行；已启用的托管实例随 Orbis 应用重新打开恢复，AI 可查询、启动和停止。
- 连接设置面板支持收起、重新打开、显示名修改、验证状态与完成后的提示收尾；模型工具能力随配置启用。

## 消息与可靠性

- 人类可在自己的消息菜单撤回；AI 撤回工具处理最近 20 条自己的正文回复，单独计算 AI 条数。人类侧显示占位；所属 AI 保留其已撤回正文与标记。人类撤回的消息在后续模型输入中显示占位。
- 修复 RikkaHub / Kelivo 长记录导入路径、保存恢复冲突、WebDAV 错误阶段提示，补齐普通回复和独立续聊完成通知。
- 新增支持开发者入口；蓝牙保留原直连与独立调试台，导入兼容上游方案并提供具体写入模式诊断。此次小众设备额外适配收尾，未验证的实物动作保留原状态。

## 使用与验证

- 直连 Pro 使用新版客户端；经 ST 使用时，服务器也需要具备新版缓存布局协议。实际缓存读取量和费用从供应商回执查看。
- 完整操作手册通过 `orbis_help` 查询；模型请求会包含已启用工具的描述、必要状态与本次实际返回的章节。
- 健康记录保存在本机独立区域，普通、云端与 Rescue 备份范围不包含该区域。工作区、图片原件和各类记录按对应入口保全。
- 撤回影响界面、检索引用和后续模型请求。此前服务请求、数据库原载荷和已有备份保留各自记录。

本次功能基线为 Dev140。对应 app / ai 单元测试共 6073 项通过，4 项私人数据探针按默认跳过；缓存请求布局同时经过 ST 配套回归和合成真实 API 对照。维护者已完成真实对话缓存验收；此前问卷、续局、导入、主题、语音条身体状态、撤回和手机 ST 安装及应用重开恢复也已收到验收回报。

vivo 个别机型通知仍待对应用户复测；蓝牙新增方案的推进、吮吸等实物动作未验收。HTTP 413、大型备份慢链路超时等独立问题继续跟踪。正式 APK 的签名、构建与下载校验信息随 Release 附件提供。
