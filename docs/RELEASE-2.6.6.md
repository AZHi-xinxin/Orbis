# Orbis 2.6.6

正式包名 `org.orbis.agent`，版本代码 `247`，沿用原正式发布签名。本次汇入本机助手记忆 V1、元信息星图，以及导入、通话、音频和设置保存修复。历史 [2.6.5](RELEASE-2.6.5.md) 的说明、标签与安装包保持不变。

## 本次更新

### 本机助手记忆 V1 与元信息星图

- 每位助手有独立的本机便签，换聊天窗口可主动查询，其他助手不能混读；不会自动迁入旧 RikkaHub 全局记忆、LC 记忆或 ST 内容。群聊和 AI 间咨询不提供这套私聊记忆的工具或自动带入。
- 默认轻档只保存和主动查询，**完全不自动带入**。标准档与独立档按各自预算处理常驻和条件命中；停止自动带入不删数据，也不禁止 AI 存查。相同人类消息的工具续轮与重试复用选择，避免反复召回和重复推进频率。
- **300 字只限制自动带入的原文，不是存储上限。** 长原文在单条容量范围内完整保存，不静默截短；AI 可自行提供摘要用于带入。真正超出保存容量时明确拒绝，不能把它当作无限存储。AI 主动压缩上下文成功时，总结可另存为「仅存」；手工归档不冒充 AI 记忆。
- AI 通过工具决定写改删、标签、状态和浮现。人类界面只提供资源档位、停止自动带入、匿名统计、导出保全及星图入口，没有正文／摘要列表、逐条审批或内容编辑按钮。想暂停某条，在对话里请 AI 使用工具处理。
- 星图就在本次 V1 内，不另列 V2。本机、ST、演示来源分开；本机仅展示数量、状态、标签族、时间、编号、版本号等元信息，不显示正文或摘要，也不套用 ST 模块分类。同标签连线只表示已有标签共现；图是有界快照，不在每一帧扫描全库。
- 单助手 JSON 导出用于保全，包含完整正文、软删记录和保留版本；当前没有一键覆盖恢复或跨助手导入。界面隐藏内部工具内容不等于加密保密：被 AI 查询或自动带入的内容仍会发给所选模型，导出和原始备份也不会自动脱敏。

详见[本机助手记忆使用与边界](LOCAL-ASSISTANT-MEMORY.md)。

### 导入、通话与保存修复

- **聊天导入**：RikkaHub 按聊天结构读取，不再仅凭版本号拒绝；改进不同内容类型的保留说明、失败阶段提示及导入／跳过／附件计数回执。中断时保留已完成窗口，重新选择同一原包可跳过已有窗口；回执丢失或中断不冒充精确完成。DeepSeek 增加 `TOOL_FIND` 历史片段支持，未知片段明确停止，不静默丢弃。不执行历史工具、不导入原账号权限，也不承诺所有附件和格式都能无损迁移。
- **暂停后继续聊天**：关闭「待发消息与暂停处理」提醒后可发新消息，不必等待旧远端请求核对完成。旧队列与未知结果仍保留，不自动重发旧消息、重做旧工具或恢复旧通话；解除本地拦截不代表远端已空闲。
- **通话上下文**：改进旧回复取消、迟到转写和新通话的归属隔离；已结束通话的状态只注记到对应历史，不再追加成一条假的新用户发言。
- **通话音频**：音量键在全屏和收起时控制通话音量，不自动改音量档位。改进焦点丢失／恢复、模式拒绝、耳机拔出和路由清理；蓝牙请求被接受后仍需确认实际路由。无法确认时暂停，耳机断开不擅自转为外放。没有针对所有 OEM、蓝牙耳机和音频服务重新验收。
- **设置与数据保护**：读取失败不再被当作空配置写回；整份更新在持久事务中使用最新设置，旧读取结果和过期页面快照不能覆盖较新的保存。助手移除确认持久成功后才清理相应资料；改进原子文件中断写入后的恢复判断。不把这些保护描述成损坏数据已自动修复。
- **模型识别**：补充精确 `deepseek-flash` 模型 ID 的能力信息，不把任意同名别名推断为相同能力，也不覆盖用户已有模型设置。

## 下载与升级

- 常见 ARM64 手机选择 `Orbis-2.6.6-arm64-v8a.apk`；相应设备或模拟器可选 `Orbis-2.6.6-x86_64.apk`；不确定时选择包含这两种架构的 `Orbis-2.6.6-universal.apk`。不含 32 位 ARM，最低 Android 8.0。
- 从[官方发布页](https://github.com/AZHi-xinxin/Orbis/releases/tag/v2.6.6)下载；升级前先在应用外保存并核对备份。相同包名和签名的正式版可覆盖升级，不要先卸载或清除数据；真正的签名冲突应停止核对。
- 2.6.1／2.6.2 若遇到旧更新器证书读取误报，可手动下载新版覆盖一次。此兼容修复始于 2.6.3，不是本次更换签名。
- 本版数据库升级到 Room schema 28，为本机助手记忆增加独立表；保留原聊天与旧记忆表，不自动搬迁旧库。升级后不要直接覆盖旧 APK 回退，旧版未必能打开新数据库；回退应先核对适用备份与[恢复边界](UPDATES-AND-ROLLBACK.md)。
- Dev 与正式版分别保存数据。用户验收的 dev72 不会自动迁入正式版，也不要为了安装正式版先卸载 Dev。源码中的 debug 后缀仍为 `-orbis-dev.72`。
- 发布资产另含 `Orbis-2.6.6-source.zip`、`Orbis-2.6.6-native-source-index.json`、`Orbis-2.6.6-SOURCE-ACCESS.txt` 和 `SHA256SUMS.txt`；保留上游及第三方许可。源码压缩包不是安装包，校验清单中的 APK 摘要也不是签名证书摘要。

## 验收范围与当前限制

用户已验收本轮 dev72。自动回归覆盖本机记忆、数据库升级、导入、暂停隔离、音频路由策略、窗口音量控制和设置并发保护等关键路径；合成测试不等于每个真实模型、远端网关、手机厂商或耳机都已通过。

Dev 手动覆盖安装、正式签名／R8 构建检查、正式版应用内下载与覆盖升级是不同的验收范围，不能互相替代。正式 APK 的来源与签名应按[发布签名说明](RELEASE-SIGNING.md)及随包校验清单核对；本页不把 Dev 验收写作完整自更新链路已通过。

本机记忆不提供语义检索、跨助手共享、旧库自动迁移或后台循环模型整理。外部模型、网关、识别、TTS 的网络与限额问题仍可能影响使用；长通话的图片上下文和前端负担也没有因此全部解决。咨询室继续关闭。

更多说明见[上手指南](GETTING_STARTED.md)、[更新记录](CHANGELOG.md)与[隐私及备份边界](PRIVACY.md)。
