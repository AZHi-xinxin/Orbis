# Orbis 2.6.0

Orbis 的首次公开版本：一个原生 Android AI 客户端，把聊天、本地后花园、藏书阁共读和海龟汤放在同一个应用里。可以完全从本地开始，不需要先部署 VPS；有需要的用户也可连接自己的 Orbis 网站及配套 Supabase 服务。

## 下载与安装

从 [v2.6.0 发布页](https://github.com/AZHi-xinxin/Orbis/releases/tag/v2.6.0) 下载 APK，允许手机从你所使用的浏览器或文件管理器安装应用后，按系统提示安装。不要把源码 ZIP 当成 APK，也不需要安装 Orbis Dev。

- 最低系统：Android 8.0（API 26）。
- 大多数近年的 Android 手机：选择 `arm64-v8a` APK。
- 不确定设备架构：选择 `universal` 通用 APK，文件会更大；通用包包含本项目构建的 `arm64-v8a` 和 `x86_64`，不包含 32 位 ARM。
- `x86_64`：用于对应架构设备或模拟器。
- 应用版本：`2.6.0`，版本代码：`231`，正式包名：`org.orbis.agent`。

`Orbis Dev` 的包名是 `org.orbis.agent.dev`。它与正式版可分开安装，但数据空间不互通；本版没有自动把开发版数据迁移到正式版的功能。升级、卸载或清除数据前，请分别备份聊天、后花园和书库，详见 [隐私与备份说明](PRIVACY.md#备份不是全量镜像)。

## 本版内容

- 原生聊天：使用自己的模型、助手、消息分支、附件、按需工具和 MCP；保留主题、字体、背景及阅读偏好。
- 本地后花园：日历进入每一天的日记、锚点、信件等记录；展示称呼可自定义。也可选择连接自建原站，本地与云端不自动搬运或同步数据。
- 本地藏书阁：导入 TXT／Markdown 书籍，保存阅读进度、书签和批注，授权后让 AI 按章节片段共读。未导入书籍时书库为空，不必先配置云端网关。
- 本地海龟汤：与自己的 AI 一起推理，并单独配置 DM 模型接口。主持与主聊天上下文分离；模型调用仍按所选提供商计费。
- 快捷聊天：在后花园、阅读及游戏场景打开侧边聊天，选择当前 AI 的已有窗口；消息保存在原窗口，不自动把整本书或汤底交给聊天模型。
- 可选的多 AI 群聊、本地工具、工作区、语音和陪伴能力；相关工具与系统权限按需开启。

应用不附送 API Key、模型账号或额度。“本地使用”指相关数据可以保存在手机，并不表示远端模型免费或离线。开始前可阅读 [上手指南](GETTING_STARTED.md)。

## 咨询室暂不开放

北斗导航中没有咨询室入口。系统设置保留“正在开发，暂未开放”的提示，不能配置、待命、加入或调用；旧配置不能绕过关闭状态。源代码保留供开发与审阅，这不代表功能已经开放。

## 如何获得后续更新

**本版没有应用内新版本提醒、更新说明推送或自动安装。** 后续版本请手动查看 [GitHub Releases](https://github.com/AZHi-xinxin/Orbis/releases)，阅读说明并下载新的签名 APK。保持相同包名和发布签名、且版本允许时，后续 APK 可覆盖安装；升级前仍应备份。

“新版本提醒＋更新说明＋下载入口”已列为后续优化项，本版不包含该功能。

## 验收范围与已知限制

发布内容基于已经过用户真机试用的开发版功能：普通聊天、后花园快捷聊天，以及 OPPO 测试机的本地藏书阁和海龟汤工具已获得反馈；咨询室因此单独关闭，没有作为通过验收的功能发布。

这些记录来自开发版，不等于正式签名、启用构建优化后的 release 包在每台设备上都已完整验收，也不保证所有模型、MCP 服务、后台设置和备份恢复组合都可用。首次使用请先用不重要的数据试用。正式版与开发版的包名、签名和数据空间不同，不能把开发版安装成功当作正式版升级成功的证明。

反馈问题时请附应用版本、Android 版本、操作步骤和无敏感内容的复现例子。不要提交密钥、私人聊天、整本受版权保护的书籍、完整备份或带授权参数的链接。
