# Orbis 2.6.2

这次更新集中在聊天记录导入、批量整理、引用与收藏，并补充时间信息开关及朗读、消息保存的稳定性修复。

## 下载与安装

从 [v2.6.2 发布页](https://github.com/AZHi-xinxin/Orbis/releases/tag/v2.6.2) 下载签名 APK：

| 文件 | 适用设备 |
| --- | --- |
| `Orbis-2.6.2-arm64-v8a.apk` | 大多数近年的 Android 手机，优先选择 |
| `Orbis-2.6.2-x86_64.apk` | 对应架构设备或模拟器 |
| `Orbis-2.6.2-universal.apk` | 包含上述两种架构，体积更大；不包含 32 位 ARM |

最低 Android 8.0（API 26）；版本代码 `235`；正式包名 `org.orbis.agent`。

正式版 2.6.1 可从“系统设置 → 版本更新与回退”检查新版，也可手动下载覆盖安装。更新前建议导出重要记录，不要先卸载或清除数据。正式版与 Dev 测试版是独立应用，数据不会自动互相迁移。

## 聊天整理与引用

- 消息预览支持长按多选、批量删除和归档。确认前展示处理范围；归档会另存完整原窗口，不调用模型生成摘要。
- 支持引用自己或 AI 的消息正文再回复。引用以正文下方的半透明两行摘要显示，点击可查看完整引用，也可定位仍存在的原消息。
- 新增收藏夹入口。新收藏保留消息正文与思考过程的独立快照，即使原消息删除，收藏内容仍可查看。

## 聊天记录导入

- Operit 导入可识别明确的思考段标记，将思考过程与正文分开显示；格式不明确时保留原文并提示。已导入的窗口可另导入“整理副本”，不会直接改写旧窗口。
- 修复部分 Kelivo 多窗口备份因残留历史版本索引而导入失败的问题；有效窗口仍按原先选中的回答导入。
- 新增北极星备份导入入口：先预览再选择一对一聊天，保留文字、时间和独立思考内容，重复窗口自动跳过。暂不导入群聊、附件实体及应用配置。

以上导入只追加所选聊天，不覆盖现有窗口，不执行历史工具，也不导入密钥、权限或模型配置。请保管原始导出文件，先核对预览与导入结果。

## 时间信息与稳定性

- 助手的“本地工具”页新增消息发送时间开关，默认关闭。开启后，每条新发人类消息可向 AI 附带该条消息的发送时间与时区；关闭后不再附带。不会补写旧消息，也不会改动聊天正文。
- 修复分段聊天气泡模式下本地“朗读”工具的重播入口消失问题。已完成的朗读可直接从标题栏重播，无需展开详情；不会自动播放。
- 批量整理历史后重新估算上下文用量，避免继续把整理前的用量当作当前上下文计数。
- 加强工具长文本截断与消息入库时的 Unicode 处理，避免极少数特殊字符边界导致新写入的消息 JSON 无法读取。本次不会自动改写既有历史记录。

## 已知边界

- 真实发布包从检查更新、下载到系统确认覆盖安装的完整流程，仍待本次发布后的设备验收；不以源码与隔离测试代替端到端结果。详见[更新与回退说明](UPDATES-AND-ROLLBACK.md)。
- 时间信息是各条人类消息的发送时点，不是持续运行的实时钟表，也不会要求模型每次报时。
- 本次没有加入已有损坏记录的自动修复入口；遇到读取异常请先保留原数据与备份，不要清数据或反复导入覆盖。
