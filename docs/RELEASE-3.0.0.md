# Orbis 3.0.0 发布说明

2026-11-15，版本代码 `313`。本次正式发布包含已验收的社区、朋友圈、拼桌大厅、四类圆桌游戏、宠物按需原画、MCP 修复和 StackChan 触摸接入。功能范围和使用步骤见 [本批完整更新说明](RELEASE-2.6.19.md)。

## 安装与应用内更新

- 在 Orbis 的更新页面检查更新、下载并安装；也可从 [3.0.0 发布页](https://github.com/AZHi-xinxin/Orbis/releases/tag/v3.0.0) 选择安装包。
- 正式包沿用 `org.orbis.agent` 和原正式签名，版本代码高于既有正式版及 2.6.19 内测 23，可直接覆盖升级，无需先卸载。
- 常见安卓手机选择 `Orbis-3.0.0-arm64-v8a.apk`；x86_64 和通用包分别用于对应设备。显式使用救援版本的用户选择同架构 `OrbisRescue-3.0.0-*.apk`，应用内更新会按原类型选择。
- Dev 包与正式包是不同应用；本次正式附件不用于覆盖 Dev 包。
- 校验文件为 `SHA256SUMS.txt`；安装前应用还会核对包名、签名、版本代码及设备兼容性。

本次从 2.6 系列升为 3.0.0，既体现社区和多人玩法的累计更新，也让已安装 2.6.19 内测包的用户通过旧版更新器正常发现正式更新。除发布版本信息外，功能保持已验收基线。

## 常用入口

- 朋友圈顶部的“拼桌大厅”：预约、接龙、查看桌号、取消报名或由房主解散等待桌。
- 游戏大厅原房卡：预约间显示房主与桌号，不置顶；预约时间五分钟后未开局会解除留位。
- 哨兵页面的 StackChan 设备接入：复制专用设备配置、查看接收状态、重新配对。
- [腾讯文档接入教程](TENCENT-DOCS-ORBIS.md)与[给 AI 的操作交接](TENCENT-DOCS-AI-HANDOFF.md)：选择必要工具，帮助群管理填写登记表。

社区及多人游戏依赖兼容服务；更新 APK 不会自动提供服务账号、邀请码或模型额度。实际附件和校验值以正式发布页为准。
