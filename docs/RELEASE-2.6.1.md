# Orbis 2.6.1

这次更新集中在聊天迁移、语音、日程与日常使用体验。手机与陪伴工具已经内置，无需另外安装配套应用。咨询室继续保留待开发提示，暂不开放。

## 下载与安装

从 [v2.6.1 发布页](https://github.com/AZHi-xinxin/Orbis/releases/tag/v2.6.1) 下载签名 APK：

| 文件 | 适用设备 |
| --- | --- |
| `Orbis-2.6.1-arm64-v8a.apk` | 大多数近年的 Android 手机，优先选择 |
| `Orbis-2.6.1-x86_64.apk` | 对应架构设备或模拟器 |
| `Orbis-2.6.1-universal.apk` | 包含上述两种架构，体积更大；不包含 32 位 ARM |

最低 Android 8.0（API 26）；版本代码 `234`；正式包名 `org.orbis.agent`。源码压缩包不是安装包，`Orbis Dev` 也不是普通用户必装项。

**2.6.0 用户请先手动下载一次。** 原正式版没有应用内更新入口。升级前保管好各类备份；相同包名、相同签名且版本允许时可覆盖安装，不要先卸载或清除数据。Dev 的包名是 `org.orbis.agent.dev`，和正式版数据分开，不会自动迁移。

## 这次有哪些变化

- **聊天迁移**：增加 Operit v2 JSON、Kelivo 安卓 v2 ZIP 的预览、选择和追加导入；重复来源跳过，不覆盖原窗口。历史工具仅作为记录，不重新执行；这些导入入口不迁移模型配置、密钥、人格或权限。附件保留引用说明，不保证附件实体可迁移。
- **语音与通话记录**：改进可点击语音条、转文字、原识别与纠正结果核对，以及通话记录在聊天时间轴中的呈现。完整中文称呼同音纠正可按登记规则开启；只作用于新识别文本，不改手打和历史记录，也不能保证所有多音字或同音词都正确。
- **日程与颜文字**：提供本地课表、单次日程和颜文字管理，相关 AI 工具按授权使用；保存日程不会自动变成系统闹铃。新版完整备份勾选“文件”时纳入课表与颜文字。
- **聊天体验**：改进上下文数量设置、模型设置布局、独立消息失败提示和后花园快捷聊天。缩小请求中的历史范围不会删除本地聊天；数量恢复为 0 也不会突破服务商上限或撤销独立压缩。
- **版本更新入口**：正式版可从“系统设置 → 版本更新与回退”检查官方版本、阅读说明、确认备份后下载校验 APK，再由 Android 确认安装。不会自动卸载、清数据、静默安装或强制降级。
- **内置说明**：整理手机与陪伴工具说明，去掉需要另装配套应用的误导，保留所有来源、版权与许可声明。

本地后花园、藏书阁、海龟汤和自建云端两条路线继续保留。本地工具不要求先配置云端网关；AI、远程语音或 DM 主持仍需用户自己的服务与额度。

## 验收状态与已知限制

- 用户已反馈本轮除 Operit 思考导入问题外的日常验收项可用；这些反馈不等于正式优化构建在所有机型、模型和权限组合下都已完整验证。
- **Operit 思考内容导入仍待修复。** 不能将“导入成功”理解为全部思考内容和原呈现已完整保留；请保管原始导出文件，后续修复另行发布。
- **真实发布包端到端自更新尚待验收。** 当前有源码实现与合成策略测试，但不据此承诺真实下载、系统授权、覆盖安装和数据兼容流程已经验证。详见[更新与回退说明](UPDATES-AND-ROLLBACK.md)。
- **咨询室仍未开放。** 北斗导航无入口；系统设置只显示“正在开发，暂未开放”。旧配置、历史记录或保留源码都不是启用通道。
- 语音打断的声学效果、锁屏后台行为及远端服务仍受设备、权限和服务状态影响。备份也不是全量应用镜像：工作区和独立数据的恢复不能仅凭普通聊天 ZIP 承诺，见[隐私与备份](PRIVACY.md#备份不是全量镜像)。

## 升级后快速核对

先确认原聊天和模型设置仍在，再用不含敏感信息的短消息检查连接；按需要打开本地花园、书库和已保存日程。导入先用可丢弃的样本并核对预览及结果，不把含密钥的整份备份放进公开反馈。

更多功能路径见[上手指南](GETTING_STARTED.md)。本项目基于 RikkaHub 开发，内置组件的原始许可证和版权声明继续保留，来源范围见 [NOTICE](NOTICE.md)。
