# Orbis 2.6.10

本版以对话保存与语音修复为主，包含已获维护者验收的 DeepSeek 官方搜索接入。

## 本次更新

- 改善旧工具或生成队列未结束时的人类续聊保存：补齐独立持久恢复记录和保存通知，降低新消息只留在内存、重开后回到旧位置的风险。不会自动重做执行结果未知的旧工具。
- 修复续聊完成后自动朗读通知遗漏，以及关闭自己的麦克风影响对方 TTS 播放的路径；完善语音收音与播放状态恢复。
- 为语音播放增加明确的点击停止入口，修复手动停止后迟到音频继续播放的路径。实际语音打断效果仍受设备、音频路由和语音服务影响，不承诺所有机型和长时间挂机均无异常。
- AI 压缩前自动保留原对话分支，默认开启，可在上下文相关设置中关闭。分支占用本机存储，不等于独立文件备份。
- 细分屏幕共享取帧失败提示，避免把不同失败原因全部显示为已关闭或已过期。
- 调整上下文用量计算与展示的一致性；没有宣称所有“等待回复”延迟已解决。
- 新增 DeepSeek 官方 Search / Fetch 搜索与网页读取，和聊天模型独立配置；使用 ST 网关聊天时同样可选用，不需要更换聊天模型。

## 使用 DeepSeek 搜索

进入设置中的联网搜索，添加或选择 DeepSeek，填写自己的 **DeepSeek 官方 API Key**，再开启当前 AI 的联网能力。不要填写 ST 网关密钥。

搜索与网页读取会把相应查询词或网址发送给 DeepSeek 官方服务，调用可能计费；测试按钮同样会真实调用。用法与最新价格以[官方搜索文档](https://api-docs.deepseek.com/zh-cn/guides/search/)为准。没有预置任何维护者密钥，也不会自动切换其他收费服务重试。

## 更新前请注意

正式包名 `org.orbis.agent`，版本代码 `273`，沿用原发布证书。先结束聊天与通话，再直接覆盖安装；不要卸载或清除应用数据。

如果旧版仍显示“保存有问题／临时续聊”，请先把重要的新消息复制或导出并确认文件可读。**更新会结束旧进程，无法挽回从未落盘、也没有恢复记录或导出副本的文字。** 新版修复不等于能自动恢复已经丢失的历史。显示非零大小也不等于完整恢复演练通过。

维护者已确认本轮 Dev 验收通过，包括新的备份导出与语音、搜索测试；这不代表所有设备、服务商组合及旧故障现场都已覆盖。DeepSeek 导入反馈中已确认的一例来自旧版 2.6.0，升级后恢复正常，不能把所有导入失败都归结为同一原因。

ChatGPT `subscription_sharing_user_not_eligible` 个案仍待进一步查证，授权成功不保证账号具备推理权限；本版不承诺修复该服务端限制。鸿蒙工作区兼容问题仍在等待进一步信息。本版不包含宠物区、学习机等尚未实施的新模块。

## 下载

通常选择 `arm64-v8a`；不确定时可选择包含 `arm64-v8a` 和 `x86_64` 的 `universal`。附件提供签名 APK、对应源码 ZIP、原生来源说明及 SHA-256 清单。Dev 与正式版是独立应用，数据不会自动互相迁移；旧版本标签和下载保留。
