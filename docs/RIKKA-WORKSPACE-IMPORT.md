# Rikka 聊天导入与工作区边界

本轮只实现聊天的预览、选择和追加导入；不覆盖原聊天，不导入设置、模型密钥、权限或人格设定。Operit 另有独立的聊天 JSON v2 导入格式，不能用来恢复 Rikka 工作区。

只读结构核查发现，参考备份中虽有工作区数据库记录，但记录仅保存标识、路径、状态及工具授权等元数据；备份未包含对应的普通工作区文件树或 Linux 根文件系统。备份中的 `skills/` 是技能资料，不能视为整个工作区的替代品。

因此本轮**不提供工作区恢复，也不自动安装或启用备份中的技能**。不会将旧路径绑定到本机现有目录，不复制旧工具授权，不执行脚本；源备份保持不变。请单独保留原应用的工作区文件，不能把聊天 ZIP 当作完整工作区备份。

后续如果取得明确包含普通工作区文件的导出格式，需要另行实现预览与独立选择、受控新目录、路径遍历与链接拒绝、系统目录和疑似凭据过滤，并用合成样本验证；这些能力当前尚未实现。
