# Orbis 3.0.1-rc.1

Orbis 3.0.1-rc.1（code314）公开预发布，对应群内已分发的同一组 APK，未重新打包替换。

本次更新
- 世界书新增“仅扫描人类消息”和“最近人类消息前（系统条目）”位置；旧条目设置保留。常驻模式绕过关键词判断，保留关键词不会使常驻条目改按关键词触发。
- 修复本地记忆工具 emotion 枚举中的空值，兼容经 OpenAI 兼容接口接入、拒绝空枚举的 Gemini 服务；清除情绪与旧记录兼容。
- 缓存诊断增加系统消息来源、多模态字节规模和同一次请求的用量关联。消息字节数包含内嵌图片编码等内容，不等同 token；没有返回缓存用量时不直接认定为零命中。
- 带上近期 DeepSeek 官端导入兼容、网页夜间配色、只读网页加载、重复入口清理与长 MCP 授权列表滚动等修复。

缓存问题说明
群内多位使用者反馈正常，仍有个别 Claude 接入场景出现缓存读取偏低。该个案尚未确诊，不将原因确定归于世界书、模型或中转站，也不宣称本版保证缓存命中率。本次发布不再等待该个案；诊断功能保留，只有获得新的有效证据后再继续排查。
这是 rc.1，不包含后续 rc.2 的 Claude 原生协议诊断增强，也不包含本地开发版新增的 ElevenLabs HTTP 错误分类或私人语音转发服务。

安装与下载
通常下载 arm64-v8a；universal 包含 arm64-v8a 与 x86_64，不含 32 位 ARM。三个 APK 均为正式包名 org.orbis.agent、原正式签名，可覆盖原 Orbis，保留数据，无需卸载。个人开发版 org.orbis.agent.dev 是独立安装身份，不能拿此 APK 替代其原位升级。
此版本保留 rc.1 预发布标识；正式稳定版仍为 3.0.0。附完整对应应用源码、原生依赖源码索引与 SHA256SUMS.txt，构建参数为 -PorbisReleaseCandidateSuffix=-rc.1。

验证范围
135 项针对性单元测试通过；正式 3.0.0 → rc.1 的隔离 Android 升级验证通过，合成聊天、选定设置、UID 与两次冷启动保持。主包 SHA-256：7a0f2acf25128a1ab2a295f083f3564977bd7d851d5c806106d78c71890d297b。
群内反馈不是所有机型与服务商的覆盖测试；Gemini 原反馈者的同线路复测、个别服务商真实缓存行为仍不作已验承诺。
