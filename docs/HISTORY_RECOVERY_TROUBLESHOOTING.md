# 聊天保存与停止生成

Dev227 候选将主聊天、快捷聊天和停止后的续聊统一到同一份当前会话状态，按会话串行保存到手机本地数据库。正常保存和后续编辑不再要求整份历史与旧数据库快照逐字段相等。

点停止后，以当时屏幕已显示的回复为准。旧生成即使晚到文字或完成回调，也不能重新写入当前聊天。存在差异的旧恢复副本单独保留，不把未显示的后半段自动补回窗口，也不重放旧工具或队列。

快捷聊天按该条消息的实际保存回执处理草稿：暂时有其他保存工作时继续等待；真实写入失败时显示原因并保留草稿，之后保存成功仍会更新这条回执。不会因为一次暂忙就永久显示“保存尚未确认”。

仍在生成或等待工具确认时，编辑相应历史需等本轮结束。磁盘写入失败、会话归属改变、预览后又发生新的整理，仍会提示具体原因。冷启动恢复仍核对恢复副本来源，避免把其他会话或已删除分支混入当前记录。

如果旧版出现 `history_save_not_aligned`，它指本机窗口和保存记录的比较失败，不能直接归因于模型或网络。无需卸载或清数据；反馈版本、触发操作与自检信息即可，不要在公开诊断里附聊天正文或凭据。

候选的构建、安装和真人验收状态以对应阶段回执为准。
