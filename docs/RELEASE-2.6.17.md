# Orbis 2.6.17 · 聊天恢复、导入与连接修复

本版合并 Dev167–172 的修复，继续保留 2.6.16 的音乐、人类思考链、NovelAI 生图和历史图片功能。

## 天气与日常工具

天气主来源不可用时增加备用查询，并区分城市未设置、同名地点、连接失败、限流和无效返回。结果显示实际匹配地点、来源及数据时间；不会按 VPN 出口推测你的位置。同名地点无法确定时，需要补充地区或明确坐标。

天气城市入口：**北斗导航 → 手机与陪伴 → 本地资料 → 天气城市 → 保存**。[排查方法](COMPANION_WEATHER_TROUBLESHOOTING.md)。纪念日的无效日期也会明确报错，不再返回成功。

## 申请继续与聊天恢复

- 修复部分使用过独立续聊的窗口，在保存收尾或留有旧网关等待状态时，无法提交「申请继续」的路径。申请仍受所属助手、暂停范围和最多三次的规则约束。
- 修复停止生成后，已完成的旧恢复记录仍挡住编辑、删除或新消息的路径。历史存在差异时先完整保全恢复副本，再释放活动位置；不自动合并不同历史、不重跑工具。
- 失败提示更具体，并保留待发送草稿。[恢复记录说明](HISTORY_RECOVERY_TROUBLESHOOTING.md)。

以上对应已定位和隔离复现的路径，不代表所有旧窗口异常均有同一原因。

## Operit 聊天导入

按内容结构兼容 Operit v2/v3 的 `content` 与 `sections`，支持文件夹等扩展元数据、分段思考和较长工具循环。较长记录按已有内容段保留，导入工具历史不会执行工具；重复导入继续去重。

标明归档版本但版本号尚未识别时，会先检查内容结构并提醒。关键角色、正文或分支无法确定时仍停止；未知内容段以原始 JSON 文字保留并提示。**这不是对所有旧格式或未来版本的无限兼容承诺。** [导入范围与排查](OPERIT_CHAT_IMPORT.md)。

## 连接、授权与健康同步

- 模型路由支持中文、方括号、全角符号和名称中间的普通空格，保存与转发保留原名称。过长或含隐藏控制字符的名称会明确拒绝，不再静默截短。接入 ST 时，服务端也需支持这套规则；本次 Orbis 发布不包含 ST 服务更新。
- MCP 许可按具体工具和连接身份核对，无关工具刷新或显示名称变化不再使原许可失效。地址、认证或工具参数结构改变仍需重新核对权限；升级后旧的单项许可可能需要首次重新确认。
- 对 Streamable HTTP 返回成功后立即断流、随后快速重连的情况增加次数限制，失败后明确显示状态，不自动重放工具。旧式 SSE 不属于这项专项修复。
- 保持局部重生成与审批恢复时的工具目录一致，修复由该差异引发的 ST 续轮拒绝路径；其他 HTTP 409 仍需按实际错误排查。
- 健康同步保留 MCP `structuredContent`，支持日期与日汇总步数。不会将日汇总冒充实时测量，也不凭空生成心率或睡眠数据；已有手动记录保持。
- 自检保留可识别的机器错误码、HTTP 状态、参数名和失败阶段。旧版仅记录为未分类的错误，升级后无法倒推出已经丢失的详细原因。

## 下载与升级

版本代码 **283**，Android 8.0 及以上。一般手机选择 `Orbis-2.6.17-arm64-v8a.apk`；`x86_64` 供对应架构设备或模拟器使用，`universal` 包含这两种架构。

正式包 `org.orbis.agent` 沿用原正式签名，可覆盖旧正式版。先结束生成或通话，不卸载、不清数据。`OrbisRescue-` 是同包名同签名的备用恢复入口包，按需使用。Dev 是独立应用，数据不会自动迁移到正式版。

发布页保留旧版，并提供对应源码 ZIP、原生依赖来源索引和 SHA-256 校验值。

## 验证与仍待反馈的部分

开发修复已完成针对性测试与整合回归；天气备用查询在维护者手机实际调用通过。正式包发布前另核验原签名、六个 APK、原生库与 16 KB 对齐、优化后离线推理，以及隔离模拟器从 2.6.16 覆盖升级的合成聊天和设置保留。

真实 Operit 归档已经完成解析及内容对账，数据库追加、重开与重复导入使用隔离测试验证；这不等于所有用户归档和手机都已实测。第三方原暂停窗口、健康服务以及其他授权、409 或 SSE 情形仍需各自复测。静态 16 KB 对齐不等于在 16 KB 内核真机上运行验证。

反馈请附版本、接入方式、操作步骤和具体错误码；不要公开密钥、数据库或私人聊天。
