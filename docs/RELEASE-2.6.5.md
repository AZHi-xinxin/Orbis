# Orbis 2.6.5

正式包名 `org.orbis.agent`，版本代码 `246`，沿用原正式发布签名。本次汇入视频通话、共同空间、历史迁入及界面改进；已发布的旧版本、标签与安装包保持不变。

## 本次更新

- **视频通话**：在语音通话基础上按设定间隔发送相机画面，并非连续视频流。可切换镜头、收起通话、即时查看一帧及在有效期内回看。模型须支持图片；声音仍经语音识别转文字、再用 TTS 播放，不代表模型直接听到了音色和语调。
- **通话稳定性与恢复**：修复新口述打断旧回复时，旧任务未完成收尾而把后续通话一并暂停的问题；改进网关断流、忙碌状态核对与有限自动恢复。保留聊天侧处理入口，不自动重发旧消息、重做有副作用的工具或擅自开启麦克风。
- **通话画面留存**：AI 可将本次通话的有限画面保存到照片墙。其余临时图片在挂断后 10 分钟到期，应用运行时清理、进程停止则下次启动补清；不进入普通完整备份或紧急救援包。已正式保存的照片按照片资料备份。
- **共同空间**：增加助手对应的秘密基地、动态与照片墙，支持照片备注与相关工具；与隐私室的加密和限时阅读权限是不同功能，不混用权限承诺。
- **Claude 历史迁入**：支持先预览、再选择完整会话路径，各分支分别建立聊天窗口。思考单独呈现，历史工具只作为文字，附件保留引用说明；相同内容版本跳过、变化后另建窗口，不覆盖原聊天，也不导入账号、密钥和工具授权。此入口已由用户使用真实记录验收。
- **附件与备份**：增加附件保护及清理边界；完整备份勾选文件时包含共同空间、照片与备注等对应资料。恢复前核对内容与冲突，不把缺失资料当作已恢复，也不自动解除已有附件保护。
- **界面与日常体验**：调整状态栏背景、季节主题、导航、聊天输入和通话记录展示，改进照片墙布局、颜文字、海龟汤草稿与部分页面切换行为。状态栏与主题显示仍受系统和设备设置影响。

## 下载与升级

- 常见 ARM64 手机选择 `Orbis-2.6.5-arm64-v8a.apk`；相应模拟器选 `x86_64`；不确定时可选包含两种架构的 `universal`。不含 32 位 ARM，最低 Android 8.0。
- 升级前先在应用外保存并核对备份。已有正式版可直接覆盖升级，不要先卸载或清除数据。
- 2.6.1／2.6.2 若遇到旧更新器误报证书读取失败，请从 [官方发布页](https://github.com/AZHi-xinxin/Orbis/releases/tag/v2.6.5) 手动下载并覆盖。真正的签名冲突应停止核对，不绕过校验。
- Dev 与正式版是两个不同应用，不共享聊天与配置；本次主手机 Dev 更新不等于把 Dev 数据迁入正式版。
- 发布附对应源码、原生组件来源索引、源码获取说明与 SHA-256 校验清单，保留上游及第三方许可。

## 验收范围与限制

- 用户已确认本轮网关与官端模型的视频通话验收通过。这不是所有手机、网络、模型和 MCP 组合的稳定率保证，也不代表不再可能遇到服务端故障。
- 长视频会增加图片上下文、服务用量和前端显示负担，本次不宣称已解决长时间通话的性能问题。可按需要调长抽帧间隔，并在开始前整理上下文；原始历史不会因此自动删除。
- 自动恢复只在当前会话、请求归属与工具状态能安全核对时进行。未知的工具结果不会当作已完成；挂断、静音及音频焦点等用户状态必须继续生效。部分网关能力需要配套 ST 更新，不能推及任意第三方网关。
- 历史迁入只迁移相应格式支持的内容，不是完整账号或全部媒体恢复。请保留原始导出包，并先少量预览核对。
- 本次没有针对 ElevenLabs 的服务端故障修复。外部 TTS、识别与模型服务仍受其网络、限额和可用性影响。
- 公开正式版从旧版到新版的完整应用内更新流程，仍需与 Dev 手动覆盖安装区分；不能用后者代替前者的验收。咨询室继续关闭。
