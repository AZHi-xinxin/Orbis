# 人类思考链

有些话想直接说，有些心绪想另写一处。人类思考链为这两种表达提供同一条消息中的两个位置：思考链与正文。

2026-11-03：本功能及可折叠输入已获实机验收，纳入 [Orbis 2.6.16](RELEASE-2.6.16.md)。

思考链输入默认收为一行，点开填写，透明度跟随输入区设置。

## 开启与关闭

1. 打开「当前助手设置 → 本地工具 → 允许 AI 开启人类思考链」。首次使用时授权默认关闭。
2. 授权后，AI 可以通过 `orbis_human_thought` 选择开启、关闭或查看状态。想试用时，可以在对话里告诉它。
3. AI 开启后，Android 聊天输入区提供思考链与正文两个输入位置。思考链默认显示为一行入口，点击展开填写。

授权和输入模式作用于当前助手。人类可随时关闭总授权，AI 也可以主动关闭模式。重新打开总授权后，由 AI 再次选择开启。

## 写下想分享的部分

思考链是人类主动填写的补充想法。正文沿用普通消息的发送条件；思考链可以留空，也可以写一句话或一段文字。

入口旁的「已填写」表示已有内容，收起后仍随正文发送。展开的输入框最多显示三行，长内容在框内滚动；背景跟随现有输入区透明度调整。发送完成后，入口重新收起。

点击发送后，两部分随同一条用户消息送达，AI 收到的标签是 `【人类思考链】` 与 `【正文回复】`。空思考链明确标为 `（为空）`。例如：

```text
【人类思考链】
其实还有一点舍不得今天结束，想和你再待一会儿。

【正文回复】
再陪我听一首歌吧。
```

两部分保持普通用户消息的权限。如何回应、是否提及其中的想法，由 AI 结合对话判断。

## 消息显示与后续操作

- 发送后，思考链默认折叠；标题只写「思考链」，点击展开或收起，不显示时长。
- 正文保持正常消息字号。空思考链展开时显示「（为空）」。
- 编辑消息时，两部分可以分别修改；待发队列中的已有思考链也可编辑。
- 复制与 Markdown 导出保留两部分标签；引用回复选取正文。
- AI 关闭模式后恢复普通输入，已发送的两栏历史保留。未发出的思考链草稿暂留当前输入页，关闭模式后的普通发送仅提交正文；重新开启可以继续编辑草稿。

Android 提供双栏输入；Web 支持折叠查看、复制和导出，编辑正文时保留已有思考链。

## 数据与费用

两部分随聊天保存在本机，并在模型请求中发送到所选服务。使用 ST 等网关时，它们也会经过该网关，后续处理沿用当前连接配置。折叠控制界面显示，AI 仍收到已发送的两部分。

开启或关闭输入模式由工具完成。思考链与正文合并在同一条消息中；增加的文字计入模型输入用量，实际费用以服务商记录为准。聊天副本和导出文件也可能包含思考链内容。

## AI 工具速查

| 操作 | 参数 |
| --- | --- |
| 查看输入模式 | `{"action":"status"}` |
| 开启双栏输入 | `{"action":"enable"}` |
| 关闭双栏输入 | `{"action":"disable"}` |

工具名为 `orbis_human_thought`，内置说明书章节为 `human_thought`。人类授权后工具才提供给当前助手；回执中的 `ok` 与 `enabled` 表示执行结果和当前模式。
