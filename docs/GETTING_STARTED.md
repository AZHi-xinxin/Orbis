# Orbis 上手指南

第一次使用，建议先完成普通聊天，再尝试共读和游戏。后花园可以完全走本地路线，不需要先部署服务器。

## 1. 安装并保留旧数据

使用本仓库实际发布且与你设备匹配的安装包。不要直接卸载已有应用来解决升级问题，也不要假定不同包名、不同签名的版本能覆盖安装或自动迁移。

如果已经有聊天、花园或书库数据，先分别导出备份，并确认文件能找到、大小合理。备份存在不等于已经验证过恢复。

## 2. 配置自己的模型

1. 打开系统设置中的“自定义连接与模型”。
2. 按提供商的说明填写连接类型、接口地址和 API Key，再添加它支持的模型。
3. 为当前 AI 选择模型。添加连接与实际选择模型是两步。
4. 发一条不含敏感信息的短消息，确认所选模型能够回复。

模型费用由你配置的服务决定，Orbis 不提供免费额度。不要把其他产品的订阅或登录状态当作已有 API 额度。

暂时不需要搜索、MCP、语音或自动唤醒时，不必配置这些功能。界面显示“已配置”也不等于连通性已经验证。

## 3. 选择后花园路线

### 路线 A：直接在手机本地使用

打开“后花园 · 存储与称呼”，保持本地存储。可以设置花园名称、自己的称呼和伙伴称呼；这些展示设置不会替你修改助手名、人格或聊天历史。

花园文字、本地书库和对局保存在这部手机。记事和阅读本身不需要模型；请 AI 共读或请 DM 主持时，仍需要可用的模型连接。

本地数据不会自动同步到另一部手机。卸载、清除数据或换机前，请分别备份。

### 路线 B：连接自己的 Orbis 网站

这条路线适合已经部署好网站的人。你需要一个可访问的 Orbis 网站，以及与该网站版本匹配的 Supabase 数据库、登录和访问规则。只有一个空的 Supabase 项目还不够。

1. 在“后花园 · 存储与称呼”填写自己的 **Orbis 网站 HTTPS 主页地址**，不是 Supabase 项目的 API 地址。
2. 可以先选择“保存地址（暂不连接）”。
3. 点击“连接原主页”，核对提示中的目标后确认。
4. 在网站自己的登录界面完成登录，不在应用的主页地址栏填写数据库管理密钥。

网站的数据、权限、自动同步规则、可用功能及费用，由你部署的站点决定。应用内的连接入口不是一键部署工具，也不保证任意 Supabase 站点都兼容。

需要返回本地时，选择“使用本地新空间，保留远端地址”。切换前先保存网页里未提交的编辑。切换不会迁移或删除数据；关闭连接也不会删除已经保存到网站的内容。

## 4. 导书与 AI 共读

进入本地后花园的“藏书阁”，使用导入入口，通过系统文件选择器选择 `.txt` 或 `.md` 文件。

- 支持 UTF-8、GBK／GB18030，以及带 BOM 的 UTF-16 文字。
- 单本文件与转换后的 UTF-8 正文均需不超过 32 MiB；本地书库另有总量限制。
- 本地藏书阁不是通用 PDF、EPUB 或扫描书导入器。聊天附件能打开的格式，不等于藏书阁也能导入。
- 只能导入你有权保存和使用的内容；文件读取或格式校验失败时，先检查文件，不要反复清空书库。

AI 可以按工具读取本机书目和章节片段；这些片段会发给当前聊天模型。它不会因为你导入文件就自动把整本书上传，但不要把藏书阁当作与 AI 完全隔离的私密保险箱。

允许 AI 写批注时，在当前 AI 的原生工具中开启相应选用，并按提示批准。AI 读取片段不会代替你更新人的阅读进度。

使用藏书阁自己的导出入口备份书籍、书签、进度和批注。它与聊天 ZIP、花园文字备份是不同的文件。

## 5. 配置海龟汤的独立 DM

DM 是主持人模型，你的聊天 AI 是一起推理的伙伴。这两个角色可以使用同一个提供商账号，但主持请求不会沿用主聊天历史。

在设置中的“独立 DM API”选择其中一种方式：

- **复用已有模型**：从符合条件、已启用且填好密钥的直连模型中选择。没有可选项时，先配置提供商。
- **单独填写 API**：填写支持 OpenAI-compatible Chat Completions 的 HTTPS 基础地址、模型 ID 和 API Key。基础地址不要再追加 `/chat/completions`。

保存并选择 DM 不会立即调用模型。开始游戏后，每次主持判断或评分仍需在游戏页面逐次确认，可能产生费用；结果未知时不要假定请求未发生并连续重试。

主持请求包含本局汤底、事实、公开问答和本次内容，不包含主聊天、伙伴设定或私人记忆。自定义远端接口可能有自己的处理逻辑，应用无法保证它不会另加上下文，请选择可信服务。

伙伴默认可查询公开进度。允许伙伴提出操作建议、用提示或揭底，与真正请求 DM 是不同步骤；未揭底前不会把汤底作为公开进度提供给伙伴。

## 6. 在花园里快捷聊天

点击当前 AI 头像旁的“聊聊”，选择该 AI 的已有聊天窗口。消息会存回选中的原窗口，而不是另建一个花园专用 AI。

快捷聊天不会自动把当前书页或汤底加入消息。希望讨论某一段时，可以明确引用内容，或让 AI 按已提供的工具读取允许的片段。发送前核对当前 AI 和窗口；换窗口与收起面板不会替你发出消息。

## 7. 逐项开启工具和权限

先看当前 AI 的“原生工具”选用，再看具体操作是否需要批准；手机系统权限还要单独授权。一个开关不能代替全部授权。

- 本地花园的 AI 读写，需要按助手明确开启。授权涉及本机共用花园，不只该助手自己的记录。
- 本地书籍和海龟汤公开进度的读取、写批注和推进操作，权限范围不同。
- 日历、麦克风、通知、应用使用情况、屏幕观察、蓝牙等，只在确实需要相应功能时开启。
- “以后允许”等持久授权应谨慎选择，之后可以撤回；外部 MCP 的能力以服务实际提供的工具为准。

后台唤醒、提醒和语音会受 Android 省电、联网和服务状态影响，不保证准点执行或已经被人听见。

## 8. 咨询室暂不开放

开源版默认关闭咨询室，不能配置、待命、加入或调用。源代码仍保留，但不是使用入口；不用为它填写服务地址或凭据，也不应尝试借用旧配置启动。

## 遇到问题时

### 新增的格子与隐私室

在格子里保存文字、HTML 或问卷作品，也可以授权当前助手创作和修改。HTML 支持隔离运行与全屏查看，不是联网浏览器；作品有版本时可以查阅旧版本。

隐私室以助手为主人：选定助手，为它创建房间，按页面指引保存恢复码并开启即可；不用另选模型，不要求使用 ST。不要把恢复码发给助手。一个助手只有自己的房间，之后换模型也不会转移主人。

想阅读时，先填写进入申请，再回原聊天请该助手处理申请。是否批准、分享哪些条目由它决定；获准内容限时只读，未批准的标题和正文不展示。私密工具记录及该轮调用后的思考不在人类前端展开，但给人的正常回复仍显示。详见[隐私边界](PRIVACY.md#隐私室与正常聊天)。

### 原界面打不开时先保数据

可从独立“Orbis 紧急备份”入口导出仍在本机的数据，等待保存与读回校验完成。救援包可能含凭据，不要发给他人；在备份保存在应用外并核对前，不卸载、不清数据。它是保全入口，不保证修复未知崩溃或恢复所有损坏文件。

### 提交反馈

先保留错误提示和原数据，核对所选模型、服务地址、权限及网络。请求显示失败或未知，不一定代表远端完全没执行。

提交反馈前去掉密钥、正文、私人图片和连接信息。不要为排查问题公开上传整份备份。更多说明见[隐私与权限](PRIVACY.md)。
