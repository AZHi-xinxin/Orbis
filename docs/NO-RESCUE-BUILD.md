# 主版与可选本地备份版

标准 `release` 为日常主版，不含紧急备份、安全模式、会话自修复的可启动入口。普通聊天保存、检查点、设置里的普通备份/导入保持可用。

`rescue` 是需要时手动覆盖安装的可选包，沿用同一版本代码、包名和签名，仅额外提供独立进程的“Orbis 紧急备份”入口。它直接进入现有原始文件备份页，不依赖聊天数据库、Compose 或助手初始化，不能承诺在所有故障下都可导出。

## 备用包的边界

- 只生成本地原始备份并另存到应用外，提供已有的文件选择器和本机下载目录两种保存方式。
- 不提供会话检查/修复、原始包导入、恢复撤回、安全模式、错误报告导出或系统设置跳转。
- 不自动更改数据库、恢复旧任务、删除聊天或清理旧诊断。备份成功不等于故障修好。
- 两种包均不因历史崩溃标记或过期救援请求拦截启动。
- 一致性复制期间仍排除活动数据写入；旧版已经开始但未完成的文件替换不会被当成正常数据库打开。这属于升级数据兼容检查，不是自修复。遇到此类旧状态须保留原件交维护者处理，当前备用包不提供修复。
- 备用图标与 Orbis 是同一个应用，不能把它当作独立安装的插件卸载。请勿卸载或清数据；切回主包用同签名覆盖安装。
- 主版启动不构造救援表单；正常启动路由透明且不留最近任务空白卡，并清除本应用已经退役的救援任务卡，不删除聊天数据。

## 构建与分发

同一源码同时运行两种构建的测试：

```sh
./gradlew :app:testDebugUnitTest :app:testRescueUnitTest :ai:testDebugUnitTest -Pandroid.onlyEnableUnitTestForTheTestedBuildType=false
./gradlew :app:assembleRelease :app:assembleRescue
```

源码默认构建没有个人正式签名，不得当作可覆盖安装的正式包分发。签名私钥不入库。

- 主版：`Orbis-<版本>-<ABI>.apk`，应用名 Orbis，默认更新通道。
- 备用包：`OrbisRescue-<版本>-<ABI>.apk`，版本显示 `-rescue`，单独下载说明。
- ABI 为 `arm64-v8a`、`x86_64` 或 `universal`。
- 两版同步发布。更新器只选择当前类型；缺对应附件时报明缺包，不悄悄换成另一类型。
- 首次换类型由用户在发布页选择，同版本覆盖须系统安装器支持。拒绝时不得卸载、清数据或强制降级，应提供同签名更高版本代码的对应包。

## 验收

检查两种合并清单中都没有安全模式/会话修复 Activity，主版没有紧急备份 Activity；备用包的入口只执行备份。验证旧崩溃标记不拦截、覆盖安装保留记录、普通备份、后台无空白卡、备份入口冷启动导出。

聊天另行验证：旧生成/工具中断后立即发新消息，新回复及新工具可用；旧回调不能回写新轮；手机、Web 和重启后的记录一致；已完成工具结果保留；正常打断无常驻警告，真实错误可关闭。

本机测试、模拟器结果与用户真机验收分开记录。未在 HarmonyOS NEXT/卓易通真机验证的改动不宣称已通过该环境。
