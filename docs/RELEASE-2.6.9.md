# Orbis 2.6.9

本次加入可直接使用的「知序」基础小部件形象，集中更新模型接入、生图工坊、工具授权与通话恢复。

## 本次更新

- ChatGPT 登录连接、模型选择与连接测试，以及文字、看图、工具往返和联网搜索适配；账号可用能力仍以实际服务权限为准。
- AI 生图工坊支持独立图片服务、参考图修改和后台制作；伙伴提交任务后可以继续聊天，结果返回发起任务的原对话。适配方舟 Seedream 图片接口。
- 修复旧窗口结束恢复后仍限制批量编辑、上下文计量显示缺失，以及下一轮衔接不完整的问题；真实未保存或正在执行的操作仍保留保护。
- 修复需要点「允许」的本地工具在部分恢复流程中无法继续的问题，改善旧队列对新消息、压缩及批量整理的阻塞；不自动重做旧工具。
- 优化长语音、打断与恢复收音，修复历史暂停队列挡住新通话的路径；已经结束的历史思考不再无限累计计时。通话仍可能偶发暂停，详见下方已知问题。
- 修复新哨兵被旧轮次挡住的路径，通知卡可折叠、展开和关闭；不自动重做执行状态未知的旧工具。
- 正常启动直接进入主界面，异常恢复保留独立救援入口。
- 小部件设置集中管理外观与角色素材，增加预览、导入导出及含文件备份支持。内置「知序」通用形象：9 个动作、8 种情绪各 3 张表情，共 33 张透明素材，不用自己画也能使用；已有私人素材不会自动替换。全屏房间仍不作为正式入口开放。
- 基础形象的发色与平常瞳色可独立选择十套配色：DeepSeek 蓝、GPT / Codex 白、Claude 橙、Gemini 蓝粉、Grok 黑、豆包紫、Kimi 灰、MiniMax 水红、GLM 银、MiMo 金。生气、激动暂用深红瞳色。名称仅指外观，不切换模型，也不表示厂商合作。
- 蓝牙 Toy 保持原有单入口，明确司沃康五档参数与愉兔协议范围。愉兔单次时长提供 5、10、20、30、40、50 分钟及 1 小时，不再提供 1 分钟档；成功更新后从本次指令重新计时，保留立即停止，不自动续期。挡位数值不等于 Hz 或线性强度百分比，相邻挡位未必有明显体感差异。

## 验收与已知问题

维护者已确认本轮 Toy、通话和小部件实机验收通过，并同意发布。通话挂断后重新发起已通过；静默期间的暂停是偶发现象，不是固定三分钟必断，根因尚未完全确认。本版不承诺绝对不暂停、所有机型通用或长时间无人值守稳定。

Toy 验收限于维护者使用的设备与操作，不代表所有品牌、协议与动作均已验证。出现异常时以设备实际状态为准，使用立即停止或设备自身关闭方式。新时长选项不是自动后台续期。

## 图片服务与数据

ChatGPT 套餐接入不等于提供图片生成后端。工坊需要另行配置图片 API，可能单独计费；不会自动切换到另一个收费服务。
工坊原图暂不包含在普通聊天备份里，请使用工坊的原图导出功能另存。生成失败或状态未知时不会自动重复收费重试。

通常选择 `arm64-v8a`；通用包包含 `arm64-v8a` 和 `x86_64`。发布附件包含签名 APK、源码 ZIP、原生来源索引及 SHA-256 清单。
正式包名 `org.orbis.agent`，版本代码 `269`，沿用原发布签名。先保全重要资料，再直接覆盖安装；不要卸载或清数据。
