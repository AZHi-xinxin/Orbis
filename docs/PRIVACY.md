# 隐私、权限与数据

本说明介绍 Orbis 当前实现的数据边界，不是“所有内容永远离线”或“不会发生数据丢失”的保证。实际发送到哪里，取决于你配置的模型、语音、搜索、MCP 和自建网站。

## 本地保存与外部请求

普通聊天和应用设置由本机保存；本地后花园、藏书阁及海龟汤也有各自的本机存储。这不代表它们全部加密，也不代表相关内容绝不会被发送。

| 操作 | 可能离开手机的内容 |
| --- | --- |
| 向模型聊天 | 本轮消息、所需历史、助手提示词、选中的附件和工具结果 |
| AI 共读 | 工具实际读取的书目、章节片段或批注 |
| 授权 AI 读本地花园 | 该 AI 查询到的记录，包括本机共用花园中人的记录和其他已授权 AI 的记录 |
| 海龟汤 DM | 本局汤底、事实、公开问答和本次请求内容；不沿用主聊天历史 |
| 搜索、远端工具、语音 | 对应服务处理所需的查询、工具参数、音频或朗读文字 |
| 自建云端网站 | 你在该站读取、编辑或发送的内容，按站点自己的规则处理 |

“本地工具”描述的是工具在哪里执行，不意味着工具结果只留在本地。结果进入对话后，可能随下一次模型请求发给你选择的提供商。

快捷聊天把消息存回你选择的原窗口，不自动附带当前书页或汤底。多 AI 群聊也不是自动共享所有私聊、记忆和私人工具的通道；请仍核对已启用的显式查询能力。

## 模型、密钥与第三方服务

模型账号、API Key 和额度由用户自行提供。请确认接口来自你信任的服务；应用无法验证自定义网关是否保存请求、另加上下文或转发到其他服务。

独立 DM 密钥在设备内以加密形式保存。这不意味着所有设置、聊天、备份或远端请求都具有同样的保护方式。

不要在聊天、问题反馈、截图或公开仓库里放入密钥、完整授权链接、Cookie 或私人地址。怀疑泄漏时，应在对应服务中撤销或更换凭据，仅删除截图或聊天不足以撤销权限。

此分支移除了上游的 Firebase Analytics／Crashlytics 集成；这不等于整个应用没有联网行为。用户选用的外部服务、网站及其资源仍有各自的数据处理规则。

## 自建云端与本地相互独立

本地路线不需要 VPS、Supabase 账号或公共站点。自建云端路线则连接你明确选择的 Orbis 网站，网站可以由自己的 Supabase 等后端支撑。

本地数据不会仅因连接站点就自动上传或合并到云端。云端站点的登录、数据库访问规则、日志、备份及删除策略，由站点管理者负责配置。关闭应用中的云端连接只停止使用该连接，不删除已存在的云端数据。

不要把数据库管理密钥放进客户端、网站前端或主页地址栏。仅有一个可访问的网址，也不能证明站点的访问控制设置正确。

## 最小权限

可以只使用普通文字聊天和本地记录，不必一次授予所有权限。

- **文件选择**：导入书籍、图片或备份时，通过系统选择器选择所需文件；选到云盘文件时，云盘应用也参与处理。
- **麦克风与相机**：用于对应的录音、语音或图像输入功能；不需要时不授权。
- **通知**：用于你开启的提醒和提示。通知显示、朗读完成都不等于用户实际看到或听见。
- **日历**：读取与创建日历事件需要相应授权；创建仍有工具批准边界。
- **使用情况与无障碍／屏幕观察**：属于敏感能力，只为明确需要的手机观察或陪伴功能开启。屏幕内容可能含其他应用的私人信息；授权后的截图或观察结果可能进入当前 AI 的上下文。
- **蓝牙**：仅在你要连接兼容设备时授权；AI 工具不能代替你选择和连接设备。

工具选用、工具执行批准、持久授权和 Android 系统权限是不同层次。撤回任一必要授权可能让功能停止；不要为了让一个不相关功能工作而打开所有开关。

## 备份不是全量镜像

升级、卸载、清除数据或换机前，请区分这些备份：

| 备份入口 | 范围与注意事项 |
| --- | --- |
| 设置中的备份与恢复 | 普通聊天 ZIP 包含设置，并按选择包含聊天数据库和部分文件；可能带有连接凭据和私人内容，不是匿名分享文件 |
| 本地花园导出 | 花园各类文字和引用的明文备份；不复制引用对应的附件本体，不包含书库或海龟汤 |
| 藏书阁导出 | 本机书籍全文、书签、阅读进度和批注的明文 JSON；不包含聊天或模型配置 |
| 自建网站备份 | 由网站与其后端单独管理，不能用手机本地导出来替代 |

普通聊天 ZIP 不等于整个应用备份：图片表情库、工作区、本机多 AI 群库、游戏战绩等独立数据不应假定包含其中。专用花园和书库备份也不能代替这些数据的备份。没有明确导出／恢复入口的数据，不能承诺卸载或换机后恢复。

导出文件可能包含非常敏感的原文。请自行选择可信的保存位置，避免公共网盘链接；需要加密保存时，应另行使用合适的加密存储方式。不要用唯一一份原数据来验证恢复。

## 日志、分享和删除

### 隐私室与正常聊天

隐私室按助手隔离，在本机加密保存房间内容。它沿用该助手当前聊天的模型、记忆、工具与上下文，不需要专用模型或 ST。人类默认看不到未批准条目的标题与正文；提交申请后，仍由助手决定是否分享，获批的只读许可有时间与前后台边界。

前端只遮盖私密工具输入输出及该轮调用之后的思考；给人的正文、普通工具和下一轮正常聊天不会因此隐藏。模型的真实工具历史保留，不能把这种展示权限理解成对服务商的保密隔离：私密请求仍可能由配置的模型服务处理，普通聊天存储也不保证完全没有私密工具原文。不承诺防拆包或服务商零留存。

恢复码请离线保存，不要发给 AI、放进聊天或公开图片。恢复码须配合原密文备份，单有码不能找回丢失的文件；本机密钥、备份和恢复码的保管需要分别考虑。

### 格子、上下文精简与紧急备份

格子中的 HTML 只在隔离环境呈现，不开放网络、持久存储、文件或宿主工具访问；不能将它当作任意联网网页的浏览器。

上下文精简工具减少下一次独立生成携带的旧思考和工具记录，不删除人类可看的原始聊天。已发给外部模型的请求不能据此撤回。

独立紧急备份用于普通界面无法打开时尽量保存仍存在的内容，包含保存后读回校验；恢复时先验证并经确认，保留恢复前副本。不保证找回已删除、未落盘或损坏的数据，外部附件和 Android 密钥库密钥可能不能随包跨机恢复。原始救援包可能包含聊天、设置和凭据且未加密，务必私下保存，不能上传公开问题区。外部备份保存并核对成功前不要卸载或清数据。

### 分享前检查

请求日志可能记录正文、请求参数、连接信息或敏感头部。导出前先检查、脱敏，不要把完整日志或聊天备份直接放进公开问题区。

删除本地记录不会同时删除已发送给模型提供商、已保存到自建站点、已导出的备份或已被他人保存的副本。卸载或清除应用数据可能使本地记录与设备内密钥无法恢复，应先确认备份范围。
