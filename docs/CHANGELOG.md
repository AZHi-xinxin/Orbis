## 2.6.5 — 视频通话、共同空间与恢复改进

- 修复口述打断旧回复时的收尾竞态，改进网关断流、忙碌核对与有限自动恢复；不自动重发旧消息或重新执行旧工具，保留人工处理入口。
- 增加秘密基地、共同动态、照片墙及备注工具；与隐私室权限独立。完善相应备份和冲突检查。
- 增加已通过真实记录验收的 Claude 聊天完整路径导入；分支独立保留，不覆盖旧聊天、不执行历史工具。请保留原始导出包与附件。
- 完善附件保护、清理和救援包边界，改进状态栏、季节主题、导航、聊天输入、照片墙、颜文字与海龟汤草稿体验。

用户已确认本轮网关和官端视频通话验收通过。长视频上下文与前端性能负担仍需后续优化，不宣称稳定率或全设备、全模型通用；咨询室继续关闭。

## 2.6.4 — 格子、助手隐私室与内容保全

正式包名 `org.orbis.agent`，版本代码 `243`，沿用原发布签名。安装、验收与边界见 [2.6.4 发布说明](RELEASE-2.6.4.md)。

- 新增格子：文字、HTML、问卷及版本留存；改进全屏阅读、尺寸适配和带背景 HTML 首帧闪白，修复长 HTML 在普通／全屏模式向下滚动时被截断的问题。页面仍在禁止网络、持久存储及宿主工具访问的隔离环境运行。
- 新增一助手一房间的隐私室，沿用当前助手而非另绑模型／ST；人类申请后由助手批准并选择分享，限时只读。仅隐藏私密工具记录及该轮调用之后的思考，正常正文、普通工具、调用前思考和下一普通轮不受影响；真实模型历史保留。
- 新增 AI 上下文记录精简工具：先预览、再批准，减少后续回传的旧思考及工具记录；支持查询与按批恢复，人类仍可看原历史，不删除正文和附件。
- 接入 Eleven v4 Text-to-Dialogue；改进长通话、工具中断、收音／朗读暂停恢复及记录聚合。
- 通话归档先由本助手整理，失败时可使用明确配置的外部备用模型并标明作者，保留原文与重试；AI 可结束当前已接通的本次通话。
- 扩大相关备份导入容量：ZIP 8 GiB、展开总量 16 GiB、流式 JSON 1 GiB；仍按来源格式、磁盘空间和单窗口限制检查，错误原因细分，不承诺无限导入。
- 新增独立崩溃自救导出、读回校验与先验证后确认的恢复入口；保留恢复前副本，不自动重新执行工具或开启权限。救援包可能含凭据，不能公开分享。
- 修复花园／主题切换、历史加载错误表现、手填 MCP 认证与 OAuth 旧状态冲突；改进手机能力诊断。移除旧 native_memory 能力与过时 LC 使用引导，保留后花园与内置记忆库。
- 同步内置说明书的导入容量和 Operit 思考导入已修复状态。咨询室仍未开放。

用户已确认 dev59 既有功能验收及 dev60 格子长内容滚动修复的主手机复验通过。正式版应用内完整自更新链路另行验收，不能由 Dev 覆盖安装或自动测试替代。

## 2.6.2 — 历史导入、消息操作与保存防护

正式包名 `org.orbis.agent`，版本代码 `235`，沿用原发布签名。安装选择、验收边界和已知限制见 [2.6.2 发布说明](RELEASE-2.6.2.md)；APK 以 [v2.6.2 发布页](https://github.com/AZHi-xinxin/Orbis/releases/tag/v2.6.2) 为准。

- 修复 Operit 思考内容的导入与呈现，支持另存整理副本；修复部分 Kelivo 历史版本索引导致的导入失败，并新增北极星一对一聊天的文字、时间及思考导入。导入仍需预览、选择和核对，不代表所有格式与附件都能无损迁移；保留导出原件，不执行历史工具或沿用来源权限。
- 消息预览增加长按多选、批量删除与归档入口；归档另存完整原窗口，不调用模型生成摘要。删除前仍需确认并自行备份。
- 改进消息正文引用，采用紧凑的两行引用预览；新收藏保留正文与思考内容的独立快照。
- 助手“本地工具”页新增消息发送时间开关，默认关闭。开启后为新发人类消息附带发送时间与时区，不补写旧消息或改动正文。
- 本地朗读工具在折叠或分段气泡的标题行保留重播入口。只有可重播的已完成记录可点击，使用该记录的历史文本；打开会话不会自动朗读，也不会重新执行其他历史工具。
- 批量整理历史后重新估算上下文用量；上下文预算不会扩大模型服务商的实际容量，计数本身不会删除本地历史。
- 加强消息新写入时的 Unicode 与 JSON 保存防护，避免预览截断切开字符代理对，并使消息序列化与恢复记录采用一致的 UTF-8 编码方式。此项不是既有损坏数据库的自动修复，不会自动覆盖旧聊天或回放历史工具。
- 咨询室继续关闭，正式版不提供启用入口。

本轮开发包已完成主手机使用验收，以及朗读重播和消息加载防护的 15 项隔离仪器测试；这不等于所有设备、模型和服务组合均已验证。2.6.1 → 2.6.2 正式包的应用内下载、安装授权与覆盖升级仍待 OPPO 实机端到端验收。2.6.0 用户可直接手动下载并覆盖升级到 2.6.2。

## 2.6.0 — 首次公开版本

以下为 2.6.0 首发时的功能与边界，不表示所有机型和服务都已验证。该版安装包和验收范围见 [2.6.0 发布说明](RELEASE-2.6.0.md)；历史发布资产以 [GitHub Releases](https://github.com/AZHi-xinxin/Orbis/releases/tag/v2.6.0) 为准。

### 聊天与日常使用

- 在 RikkaHub 原生聊天基础上整合 Orbis 的导航、主题、背景、字体与阅读偏好。
- 保留自定义模型、助手、消息分支、附件、工具与 MCP 等入口；是否可用取决于用户配置和实际模型能力。
- 增加后花园快捷聊天，在选定的原聊天窗口中收发消息，不自动发送当前书页或汤底。
- 提供独立多 AI 群聊、小游戏及按需语音／陪伴能力；不自动共享所有私聊内容，也不保证后台提醒准时执行。

### 后花园、共读与海龟汤

- 提供无需 VPS 的本地后花园，保存文字记录并设置展示称呼。
- 保留连接自建 Orbis 网站的路线，可使用与网站配套的 Supabase 后端；本地与云端不自动迁移或同步。
- 本地藏书阁支持 TXT／Markdown 导入、阅读进度、书签、批注及专用备份。
- AI 共读按需读取章节片段，不在导入时自动上传整本书；实际读取的内容会进入当前模型上下文。
- 本地海龟汤支持独立 DM 设置。主持与主聊天上下文分离，主持请求仍需逐次确认，可能计费。
- 增加花园与书库的专用导入／导出提示，明确普通聊天 ZIP 不覆盖所有独立数据。

### 工具、数据与边界

- 本地花园的 AI 读写按助手授权；本地书库、对局读取与写入操作采用不同权限范围。
- 保留工具执行确认及可撤回的授权；系统权限仍由用户选择。
- 改进部分工具续跑、失败状态可见性与持久化边界。源码中的修正和离线测试，不等于所有真实服务流程已验收。
- 移除上游 Firebase Analytics／Crashlytics 集成；用户选择的模型、搜索、语音、MCP 和自建网站仍可能联网。

### 暂不开放与已知限制

- **咨询室正在开发，开源版关闭。** 北斗导航不显示咨询入口，系统设置仅保留“正在开发，暂未开放”的提示。源代码保留，但不能配置、待命、加入或调用，也不通过旧配置继续运行。
- 2.6.0 首发没有应用内更新提醒、更新说明推送或自动更新，需手动前往本仓库 Releases 下载后续版本。
- 星空冷启动界面仍需不同设备、系统动画设置和无障碍场景验证；不把候选效果当作全部机型的体验保证。
- 语音、自动唤醒、文件解析、模型工具调用和自建网站兼容性仍受设备与外部服务影响。
- 普通聊天备份不是完整应用镜像，升级或换机前应分别核对花园、书库和其他独立数据的备份方式。

没有列为已开放的功能，请以应用内的状态和后续发布说明为准。
