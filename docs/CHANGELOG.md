# 更新记录

## 2.6.1 — 聊天迁移、语音与日常使用改进

正式包名 `org.orbis.agent`，版本代码 `234`。安装选择、验收边界和已知问题见 [2.6.1 发布说明](RELEASE-2.6.1.md)；APK 以 [v2.6.1 发布页](https://github.com/AZHi-xinxin/Orbis/releases/tag/v2.6.1) 为准。

- 增加 Operit v2 JSON、Kelivo 安卓 v2 ZIP 的聊天追加导入入口，先预览、选会话和目标 AI，再导入；不执行历史工具，不导入这些来源的密钥、人格或权限。**Operit 思考内容导入仍有待修复的问题**，不应视为完整迁移，务必保留原件。
- 改进语音条、转写核对、通话记录与聊天时间轴；可登记称呼及精确别名，在支持的系统上选择完整中文称呼同音纠正，保留原始识别文本，不改手打或旧历史。
- 增加本地课表、日程和颜文字工具；新版完整备份勾选“文件”时包含课表和颜文字，不代表包含整个工作区或所有独立数据库。
- 改进上下文数量设置、通话记录呈现、独立消息失败提示、模型设置布局和快捷聊天体验。消息数量截取不删除本地历史，也不扩大服务商上下文容量。
- 正式版增加官方版本检查、更新说明、APK 下载校验与系统安装入口；历史版本可查看，但不能一键强制降级。**真实发布包端到端自更新尚未验收**，2.6.0 用户仍需先手动升级一次。
- 更新应用说明书，明确手机与陪伴工具已经内置，无需另装配套应用；保留上游版权、许可证和来源说明。
- 咨询室继续关闭：北斗导航无入口，系统设置仅保留待开发提示。

用户已反馈本轮除 Operit 思考导入问题外的日常验收项可用；这不等于正式构建在所有设备、模型、权限组合和外部服务上都已完整验证。应用内更新单独保留待验收状态，不包含在上述通过反馈中。

## 2.6.0 — 首次公开版本

以下为 2.6.0 首发时的功能与边界，不表示所有机型和服务都已验证。该版安装包和验收范围见 [2.6.0 发布说明](RELEASE-2.6.0.md)；历史发布资产以 [GitHub Releases](https://github.com/AZHi-xinxin/Orbis/releases/tag/v2.6.0) 为准。

### 聊天与日常使用

- 在 RikkaHub 原生聊天基础上整合 Orbis 的导航、主题、背景、字体与阅读偏好。
- 保留自定义模型、助手、消息分支、附件、工具与 MCP 等入口；是否可用取决于用户配置和实际模型能力。
- 增加后花园快捷聊天，在选定的原聊天窗口中收发消息，不自动发送当前书页或汤底。
- 提供独立多 AI 群聊、小游戏及按需语音／陪伴能力；不自动共享所有私聊内容，也不保证后台提醒准时执行。

### 后花园、共读与海龟汤

- 提供无需 VPS 的本地后花园，保存文字记录并设置展示称呼。
- 保留连接自建 Orbis 网站的路线，可使用与网站配套的 Supabase 后端；本地与云端不自动迁移或同步。
- 本地藏书阁支持 TXT／Markdown 导入、阅读进度、书签、批注及专用备份。
- AI 共读按需读取章节片段，不在导入时自动上传整本书；实际读取的内容会进入当前模型上下文。
- 本地海龟汤支持独立 DM 设置。主持与主聊天上下文分离，主持请求仍需逐次确认，可能计费。
- 增加花园与书库的专用导入／导出提示，明确普通聊天 ZIP 不覆盖所有独立数据。

### 工具、数据与边界

- 本地花园的 AI 读写按助手授权；本地书库、对局读取与写入操作采用不同权限范围。
- 保留工具执行确认及可撤回的授权；系统权限仍由用户选择。
- 改进部分工具续跑、失败状态可见性与持久化边界。源码中的修正和离线测试，不等于所有真实服务流程已验收。
- 移除上游 Firebase Analytics／Crashlytics 集成；用户选择的模型、搜索、语音、MCP 和自建网站仍可能联网。

### 暂不开放与已知限制

- **咨询室正在开发，开源版关闭。** 北斗导航不显示咨询入口，系统设置仅保留“正在开发，暂未开放”的提示。源代码保留，但不能配置、待命、加入或调用，也不通过旧配置继续运行。
- 2.6.0 首发没有应用内更新提醒、更新说明推送或自动更新，需手动前往本仓库 Releases 下载后续版本。
- 星空冷启动界面仍需不同设备、系统动画设置和无障碍场景验证；不把候选效果当作全部机型的体验保证。
- 语音、自动唤醒、文件解析、模型工具调用和自建网站兼容性仍受设备与外部服务影响。
- 普通聊天备份不是完整应用镜像，升级或换机前应分别核对花园、书库和其他独立数据的备份方式。

没有列为已开放的功能，请以应用内的状态和后续发布说明为准。
