# Orbis 2.6.4

正式包名 `org.orbis.agent`，版本代码 `243`，沿用原正式发布签名。此版汇入经过 dev59 验收的功能，以及经 dev60 主手机复验通过的格子滚动修复；2.6.1–2.6.3 的历史发布、标签和安装包保持不变。

## 本次更新

- **格子**：保存文字、HTML 与问卷，支持版本留存和全屏阅读；AI 经授权可创作、修改作品。修复带背景 HTML 的首帧闪白、全屏尺寸与重复加载问题，以及长 HTML 在普通和全屏模式下向下滚动时内容被截断的问题。HTML 在隔离环境运行，不开放网络、持久存储、文件或手机工具访问。
- **助手专属隐私室**：一个助手对应一个本机加密空间，沿用原助手的模型、记忆、工具和聊天上下文，不要求另选模型、ST 或专用网关。人类填写申请，由助手决定是否批准及分享哪些条目，获批后限时只读。
- **隐私室显示边界**：只隐藏私密工具调用记录，以及该轮私密调用之后的思考；调用前的思考、普通工具和给人的正文照常显示。新一轮未调用私密工具时恢复正常展示，模型自己的真实工具历史不会被前端占位文字替换。
- **上下文记录精简工具**：AI 可预览、申请精简后续回传的旧思考与工具记录，并查询或按批恢复；下一次独立生成生效。人类历史仍可见，不删除正文、通话或附件，保护最近两个人类轮次和当前工具链。
- **语音与通话**：接入 Eleven v4（`eleven_v4`，Text-to-Dialogue）。改进长通话、工具中断、音频焦点和连接失败时的暂停与恢复，不自动重放旧录音或副作用工具。
- **通话归档兜底**：优先由本助手整理；失败时可交由明确配置的外部备用模型并注明作者。原文和人工重试入口保留，本助手之后可读原文并补写归档。AI 也可通过工具结束当前已接通的本次通话。
- **大文件导入**：相关 ZIP 入口上限扩至 8 GiB、展开总量 16 GiB，流式 JSON 上限 1 GiB，并保留格式、空间、单窗口等限制；错误提示区分原因，不静默截断。各格式能力不同，不代表任意 8 GiB 文件都能导入。
- **崩溃自救**：提供独立紧急备份入口、分阶段导出与读回校验，以及先验证、再确认的恢复入口；恢复前保留副本，不自动恢复旧工具和后台权限。只能尽量保住仍存在的数据，不能复原已删除、未落盘或损坏的内容。
- **界面与兼容性**：修复花园和主界面切换、主题生命周期相关问题；区分历史加载失败和真正的空白；改进手填 MCP 认证与旧 OAuth 状态冲突、手机能力诊断和屏幕观察错误提示。移除旧 `native_memory` 能力及过时的 LC 使用引导。
- **说明书同步**：更新应用内指南，纠正旧导入上限及 Operit 思考导入状态。

## 从 2.6.0 升级还会获得

语音条、语音称呼与别名纠正、离线课表和月／日程、颜文字库、上下文条数设置与原文整理、Operit／Kelivo／北极星聊天迁入、消息多选管理、紧凑引用、收藏快照，以及应用内检查版本、查看说明、下载校验和调用系统安装器。详见 [更新记录](CHANGELOG.md)。

这些导入属于聊天历史迁入，不是完整克隆其他应用的账号、密钥、权限和全部附件。北极星目前以一对一文字、时间与思考为范围。离线日程不等于系统日历同步或已经设置闹钟。

## 下载与升级

- 普通 ARM64 手机选择 `Orbis-2.6.4-arm64-v8a.apk`；对应模拟器选择 `x86_64`；不确定时选择 `universal`（包含 ARM64 与 x86_64，不含 32 位 ARM）。最低 Android 8.0。
- 升级前先在应用外保存并核对备份。正式版可从 2.6.0 直接覆盖升级，不需要逐版安装，也不要先卸载或清数据。
- 2.6.1／2.6.2 旧更新器若误报证书读取失败，请从 [官方发布页](https://github.com/AZHi-xinxin/Orbis/releases/tag/v2.6.4) 手动下载并覆盖一次。系统安装器仍报签名冲突时应停止核对，不绕过校验。
- Dev 与正式版是不同应用和签名，不共享数据；不要用正式 APK 覆盖或先卸载 Dev 来“迁移”。
- 发布同时提供对应源码、来源索引、源码获取说明和 SHA-256 校验清单，保留上游与第三方许可。

## 验收范围与仍需留意

- 用户已确认本轮主手机验收通过，包括格子、花园切换、工具清理、宫格位置及隐私室显示；dev60 补充复验了原有长 HTML 的普通／全屏滚动至末尾及模式切换。这不代表所有手机、模型和服务组合都已实测。
- 应用内更新包含下载、摘要／签名／包名／版本检查及 Android 安装确认，不会静默安装。从修复版到更高正式版的完整真实自更新链路仍需单独验收，不以 Dev 覆盖安装代替。
- 隐私室主要管理应用内阅读权限和本机密文，不承诺防拆包、模型服务商零留存或普通聊天存储完全不含私密工具原文。恢复码须离线保存并配合原密文备份使用，不要发给 AI。
- 紧急救援原始备份可能包含聊天和连接凭据且未加密，不要上传群聊或公开 issue；外部附件和 Android 密钥库密钥也可能无法跨机恢复。
- 网关旧请求的查询／停止需要服务端配套支持，不代表任何第三方网关都能自动恢复；VIVO 屏幕观察仍可能涉及权限、接口与设备环境，不能只按品牌认定原因。
- 咨询室仍未开放。本次为 Orbis 发布，不包含尚待独立验收的 ST 服务更新。
