# Orbis 3.0.2

正式版，versionCode 316。可从同签名的 3.0.0、3.0.1-rc.1 直接覆盖升级，保留原应用数据。主包包名是 `org.orbis.agent`；Orbis Dev 是独立应用，正式包不会覆盖它或自动搬入它的数据。

## 人类分段整理长窗口

入口：聊天顶栏圆环 → 人类手动整理 → 分段生成摘要。

- 可以指定段数、填写摘要要求，例如叙述视角、详细程度和需要保留的约定；留空段数时自动规划。
- 支持 1–4 路并发。每段成功后立即保存本机草稿，失败、暂停或重新打开后，只继续未完成的段落。
- 完成后可逐段核对和编辑。确认应用后，全部段落一起进入上下文，并分别存入记忆库；另保留一个完整原文存档。
- 规划和检查不会请求模型；开始生成后使用当前模型，按服务商规则计费。在途请求即使取消也可能已计费。
- 分段可以帮助处理超过模型输入上限的窗口，但段数过少、提示词过长或单条消息过大仍可能超限。页面会显示单段最长文字数。

摘要只处理所选分支的公开文字；附件和其他分支保留在原文存档。生成完成前不替换原聊天。断点草稿仅保存在当前设备，不随普通备份导出；不要清除应用数据来解决失败。AI 自主整理和原有手写摘要入口继续保留。

## DeepSeek 官方导出包

延续此前对旧、新版 ZIP、外层目录、长记录和可选分支的支持，本次补充：

- 容忍缺少时间、附件大小等非关键元数据；有效的新版包缺少索引时尝试恢复扫描。
- 保留思考耗时和置顶信息，展示可恢复的历史搜索引用；历史引用只供阅读，不会重新执行工具。
- 补齐文档附件的类型识别。原包不含附件文件时不会凭空恢复。

缺失的时间会明确作为未知处理。路径越界、校验失败、结构冲突等仍会拒绝导入，不因容错而忽略损坏。请保留原始导出包。

## 显示、接龙和语音

- 修复“数据与存档”页面在夜间主题下正文仍显示黑色、难以阅读的问题。
- 纯 AI 接龙按当前助手显示报名状态，避免同一账号的另一个助手被误认为已经报名；服务端既有独立席位规则保留。人机共玩规则不因此放宽。
- ElevenLabs 朗读失败会区分重定向、访问限制与其他 HTTP 错误，减少将网络问题统一提示为额度或配置问题的误导。允许使用自己配置的服务地址；本发行版不附带公共转发服务、私人节点或访问凭据。

## 下载与验证范围

通常选择 `Orbis-3.0.2-arm64-v8a.apk`；`x86_64` 用于对应架构设备，`universal` 包含两种架构，不包含 32 位 ARM。请直接覆盖安装，不要先卸载或清数据。发布附件同时提供完整应用源码、原生依赖源码索引和 SHA-256 校验文件。

本版功能已在开发包上获得用户验收；正式签名包另做构建、签名和隔离升级检查。合成测试及单台设备的通过不代表所有模型、转发服务或手机都经过测试。最终执行的测试数量与结果见 GitHub 发布正文。
