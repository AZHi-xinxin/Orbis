# 发布签名

Orbis 的公开 Android 安装包使用独立、长期保留的发布签名；不是 Android 通用 debug 签名，也不是 RikkaHub 的签名。

- 应用包名：`org.orbis.agent`
- 首次公开版本：`2.6.0`（版本代码 `231`）
- 当前发布版本：`2.6.7`（版本代码 `251`）
- 签名证书 SHA-256：`527b1f22ac8baebed936e98d77e3e05881752adc5a88af6aecfd012351f39258`

APK 的文件摘要与证书摘要不是同一个值。每次发布的 APK 文件 SHA-256 见对应 GitHub Release 附带的 `SHA256SUMS.txt`；上面的证书摘要用于核对发布者签名。

后续由本项目发布的更新应保留相同包名和签名，并增加版本代码。2.6.3 沿用上述原证书，修复 Android 9／10 读取下载包签名时的兼容问题，并未换签名或关闭验证。受影响的 2.6.1／2.6.2 用户需要从官方发布页手动下载修复版，直接覆盖一次；2.6.0 也可直接升级。不要卸载或清除数据。

应用内更新仍要求用户确认，不会静默安装。从修复版到下一更高正式版的完整更新流程仍待验收；证书读取验证不等于整条下载、授权、安装链路均已通过。详见[更新与回退说明](UPDATES-AND-ROLLBACK.md)。

`Orbis Dev` 使用不同包名和测试签名，与公开版各自保存数据。公开版不会自动读取或迁移 Dev 的聊天、配置及本地花园。

2.6.7 沿用上述发布证书，保留 2.6.6（版本代码 247）及更早标签和资产。本轮屏幕共享与 ZIP 功能、以及 `2.6.7-orbis-dev.77` 中的哨兵修复已获维护者验收与发布确认；Dev 验收不能替代正式签名 APK 的构建、证书和文件摘要核对。下载资产与升级边界见 [2.6.7 发布说明](RELEASE-2.6.7.md)。

自行构建者应使用自己的签名，不会获得本项目的发布私钥。私钥、签名密码及本机配置不会随源码或 Release 上传。
