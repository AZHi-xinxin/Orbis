# NovelAI 生图和参考图

适用于包含本次接入的版本；公开安装包是否包含这些功能请以对应发布说明为准。

在「AI 生图工坊 → 连接 NovelAI」填写同一账户的 Persistent API Token，可选 NAI 4.5 Full、V5 Full、V5 Curated。它是图片制作者，不需要把聊天模型换成 NovelAI。生成的原图保存在工坊。**人类在工坊手动生成、修改或重新制作的图片只留在工坊，不通知 AI；即使从聊天打开工坊也一样。** 只有 AI 自己调用工具发起的任务才把结果送到原对话，AI 的工坊列表、任务读取和作品参考也只开放这些任务。人类主动在聊天发送的图片仍按普通附件分享。点击聊天图片可查看/保存原图，「查看生成提示词」可展开复制提交的文字。

## 加参考图

1. 在工坊选择制作者，点击「添加参考图 / 修改图片」。支持 PNG、JPEG、WebP，单张最多 24 MB。
2. NovelAI 一次使用一张参考图，填写希望保留和修改的内容。
3. **原图重绘**：4.5 / V5 均可用。重绘幅度越低越接近底图，越高改动越大。第一次可从 30%～50% 试起，再根据结果调整；这不是保证画风一致的数值。
4. **角色与画风参考**：目前仅 4.5 支持。重新生成构图时参考外貌和画风；强度越高，参考影响越明显。不是无损复制，也不能保证人物完全一致。
5. 点击生成后可继续聊天。原文件保留，结果另存；失败不会自动重复付费请求。

V5 的参考图入口目前是原图重绘；尚未接入 Vibe Transfer、局部重绘和多张 NovelAI 参考图。不会把 V5 不支持的精确参考方式作为可选入口。

AI 工具同样支持参考图：`orbis_image_workshop.list_images` 分页列出原对话可用图片码（包括当前上传的图片），`edit` 使用 `reference_image_codes`；也可使用本对话 AI 发起的已有作品的 `reference_files`。`get(job_id, image_index=0)` 可重新读取该任务的一张原图；视觉模型收到图片，纯文本模型通过已配置的识图/OCR读取，不只返回文件名。图片码受助手、原会话和消息分支约束，不能传任意本机路径或借用另一助手的图片。`list` 会列出各模型实际开放的动作和参考方式。文本主模型可以传递已选图片，但不能因此自称看懂图片。

## 额度

- Opus 的普通免费文生图条件包含单张、正常分辨率范围（像素面积不超过 1024×1024）、至多 28 步，且不使用底图。默认文生图为单张 1024×1024、23 步。
- V5 还受独立、持续恢复的免费用量限制；耗尽后可以消耗 Anlas。不能把所有 V5 请求都视为无限免费。
- **原图重绘会消耗 Anlas**，不属于上述无底图免费文生图。
- 4.5 精确参考额外收取每张参考图 5 Anlas，基础生成是否收费另按参数和账户权益计算。
- 应用不估造账户余额，不因网络失败自动重做。以 NovelAI 账户用量和当次计费为准。

官方说明：[订阅](https://docs.novelai.net/en/subscription/)、[Opus 用量](https://journal.novelai.net/opus-usage-limit-explained/)、[精确参考](https://docs.novelai.net/en/image/precisereference/)。

## 为什么相同提示词不一定像示例

版本、种子、正负提示词、分辨率、采样器、步数、引导强度和网站默认附加标签都会影响结果；参考作品还可能做过后期处理。只拿到正向提示词通常不能复现成图。本次同种子对照中，4.5 与 V5 使用各自默认引导强度，不能据此把全部差异都归因于模型。

希望得到浅色二维插画时，直接描述细线条、二维上色、柔和光照和服饰细节，比只堆叠“高清”“杰作”更容易表达意图。若需要前景虚化，检查负向提示词是否同时禁止了所有模糊效果。不要期待仅增加步数就必然更好看。

## 工具说“图片过期”时先核对错误

`workshop_request_deleted` 表示本次 `request_id` 撞到了已删除作品的旧编号，不表示参考图过期或工坊停用。该次提交在请求生图接口之前已被拦下。删除记录会保留不含提示词和图片的编号回执，以防旧请求再次收费；新创作使用新的随机 UUID，同一任务原样重试才复用编号，不自动换号恢复已删除的任务。

`workshop_request_conflict` 表示相同编号已有不同参数的任务，也应先核对原任务。图片是否失效须按实际图片读取错误判断，不能仅凭上述两个编号错误推断。

## 历史图片开关

入口：聊天输入框左侧「＋」展开 →「对话设置」→ 下滑到「当前 AI 的生成参数」→「发送历史图片」，切换后点击「保存当前 AI 参数」。此设置影响使用同一 AI 的会话，下一次请求生效。

「发送历史图片」默认开启，保持旧行为。关闭后，本轮新增图片照常发送，旧图以稳定图片码替代；AI 可按码调用 `orbis_read_chat_image` 按需查看。聊天原图不会删除，重新打开开关仍可发送全部保留在本轮上下文中的图片。它不会把工坊的手动私密创作分享到聊天。纯文本模型读取图片时沿用现有识图/OCR能力，不会凭空获得视觉能力。

## 删除工坊图片与记录

每张已完成的图片下有「删除图片」，可单张删除；「删除记录」移除整条提示词和该批图片。确认后生效，不能撤销。排队中的任务先取消，正在制作的任务等结束后再删除，避免把正在计费的操作误当作取消。

已发送到聊天的图片、仍作为其他制作记录参考的原图保留，其余未引用原图从本机删除。工坊删除不会抹除既有聊天、让 AI 忘记已经收到的内容，或触发重新生图。删除后只保留防止重复计费所需的最小任务回执。

旧版误发的人类作品如果只是待处理通知，升级后不再显示或唤醒 AI；已经真正进入聊天的历史消息不自动删除。
